## §1 8 种 AI 人像专业光位

### 正确提示词结构

```
主光位置（相对人物/镜头）+ 软硬光性质 + 阴影形状特征 + 情绪词
```

### 8 种光位速查表

| 光位 | 灯位要点 | 画面特征 | 情绪效果 | 适用 |
|------|----------|----------|----------|------|
| **正面顺光** | 镜头正后方，与光轴重合，眼睛高度 | 面部阴影极少，左右亮度一致 | 自然、稳定、亲和 | 日常、温馨对白 |
| **前侧光** | 左/右前方约 30°，高于眼睛 20-30°，中等柔光 | 靠光源侧明亮，鼻梁另一侧留短柔阴影 | 立体、经典、耐看 | 人物主镜头 |
| **蝴蝶光** | 正前上方，水平角 0°，高于眼睛 35-45°，中等柔光 | 额头鼻梁双侧颧骨对称受光，鼻尖下短小蝴蝶形阴影 | 精致、优雅、高级 | 女角特写、唯美定格 |
| **伦勃朗光** | 左前上方，水平约 45°，高于眼睛 30°，硬光 | 暗侧脸颊出现三角形亮区，明暗对比强 | 深邃、神秘、有故事感 | 悬疑、男性、情绪戏 |
| **侧光** | 正侧方（左或右），与人物成 90°，硬光 | 面部一半亮一半阴影，明暗交界线清晰 | 硬朗、冲突、有力量感 | 硬汉、对峙、审问 |
| **逆光** | 正后方，略高于头顶，硬光 | 正面在阴影中，头发肩膀成明亮轮廓光 | 神秘、浪漫、氛围感 | 剪影、黄昏、离别 |
| **顶光** | 正上方垂直向下，硬光 | 眼窝鼻下下颌阴影明显，面部轮廓深邃 | 压迫、权威、神秘 | 反派、神明、高位者 |
| **底光** | 正下方垂直向上，硬光 | 面部下方明亮、上方阴影，阴影反常向上 | 诡异、危险、邪恶 | 恐怖、反派、火光照脸 |

### 场景适配规则

- **清新/日常/温馨对白** → 正面顺光、前侧光
- **唯美/高级/定格** → 蝴蝶光（女角特写、情感高潮定格）
- **悬疑/情绪/男性** → 伦勃朗光（密谋、心理戏、刺客暗面）
- **硬汉/对峙/冲突** → 侧光（打斗前对峙、审问、权力角力）
- **氛围/剪影/浪漫** → 逆光（黄昏离别、月光下剪影）
- **反派/权威/威慑** → 顶光（高位者俯视、幕后主使）
- **恐怖/诡异/惊吓** → 底光（火把从下照脸、井边、阴森反转）

### 落地写法（光位 + 光源动机）

光位要配合**光源动机**（画面里出现真实光源）才不穿帮：

- 逆光 → "黄昏暖金逆光从画面右后方照射，勾勒杨旭肩背轮廓，正面没入暗部"
- 伦勃朗光 → "烛火主光在张十三左前上方 45°（硬光），暗侧脸颊现三角形亮区"
- 顶光 → "天井顶光垂直泻下，眼窝与鼻下浓重阴影"
- 底光 → "篝火在人物正下方跳动，光影自下而上，面部下方明亮"

### 情绪词组合

- 逆光 + 浪漫 → "剪影轮廓染上暖金，气氛缱绻"
- 伦勃朗 + 神秘 → "三角亮区在暗影中若隐若现，眼神深不见底"
- 顶光 + 权威 → "强光自头顶压下来，逼视感强烈"
- 底光 + 诡异 → "光芒反常向上，五官在阴影中扭曲"

## §2 5 种脸型库（锁脸防变脸）

### 脸型速查对照表

| 脸型 | 核心关键词 | 气质 | 适配角色 |
| --- | --- | --- | --- |
| **猫系脸** | 细长眼、眼尾上挑、清冷警觉、小巧脸型 | 冷艳疏离、轻微攻击性 | 刺客/杀手/心思深沉女角 |
| **鹿系脸** | 大而清澈的眼、湿润眼神、饱满苹果肌 | 温柔无辜、清纯 | 白月光女主、弱质/被保护者 |
| **狐系脸** | 眼尾明显上挑、尖下巴、狡黠眼神 | 妩媚危险、聪明精明 | 妖妃/宠姬/反派美人 |
| **天鹅脸** | 修长脸型、高鼻梁、清晰下颌线 | 优雅高级、端庄 | 大家闺秀、权贵之女 |
| **雀斑脸** | 雀斑、自然皮肤、浅色眼睛、野生感 | 清冷文艺、真实素颜 | 山野/村姑/异族少女 |

### 气质 → 脸型映射

- 猫系脸 → 刺客、杀手、心思深沉的女性
- 鹿系脸 → 白月光女主、弱质、被保护者
- 狐系脸 → 妖妃、宠姬、反派美人、心机女角
- 天鹅脸 → 大家闺秀、权贵之女、名门正妻
- 雀斑脸 → 山野、村姑、异族少女、质朴配角

### 跨章一致（最高优先级）

- **脸型词必须写入角色 `static_features`**（如 `鹿系脸，大而清澈的眼睛，鹅蛋脸，黑发挽髻`），CharacterBank 首次锁定不变
- 每章肖像、首帧、视频 prompt 引用同一脸型词，禁止每章换脸型
- 与去塑料段配合：先选脸型（§3），再加皮肤真实感

## §3 去塑料感（4 要素：毛孔+红润+明暗+颗粒）

### 核心问题

AI 人像"塑料脸/硅胶感/过度磨皮"，本质是 prompt 只写"皮肤好/光滑"，没有写**毛孔、红润、明暗、颗粒**四个反塑料要素。

### 基础核心提示词（面部特写必带）

```
可见毛孔细纹，自然红润感，面部要有明暗变化，不要均匀受光，有光影颗粒，灰尘噪点，不要干净无层次
```

### 强化补充提示词

**皮肤细节**：
```
真实皮肤纹理，轻微油光质感，细小汗毛，少量面部小痣，真实唇纹，眉毛根部细节
```

**光影结构**：
```
侧光照明，柔和明暗过渡，苹果肌自然起伏，脸颊阴影层次，鼻翼到脸颊真实过渡，不要过度磨皮，不要完美对称
```

**氛围质感**：
```
自然窗光，轻微呼吸感，眼神自然停留，不要脸颊一整片发亮，不要夸张五官，不要塑料皮肤
```

### 使用范围

- **仅面部特写镜头/面部特写肖像**注入完整去塑料段
- **普通镜头/全身镜头**不注入完整段（避免 prompt 冗余）——全身已有基础"真实皮肤纹理/毛孔"
- 与脸型库配合：先选脸型（§2）定轮廓气质，再加去塑料段定皮肤真实感

### 古风适配完整示例（面部特写）

```
写实古风真人，9:16 竖屏，面部特写。可见毛孔细纹，自然红润感，面部要有明暗变化，
不要均匀受光，有光影颗粒，灰尘噪点，不要干净无层次。真实皮肤纹理，轻微油光质感，
细小汗毛，侧光照明，柔和明暗过渡，苹果肌自然起伏，脸颊阴影层次，鼻翼到脸颊真实过渡，
冷月清辉勾勒轮廓，不要过度磨皮，不要完美对称，电影感质感。
```
