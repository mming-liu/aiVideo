# 切换拍摄对象（focal-switch）

> 适配 aiVideo 古风真人竖屏分镜。
> 核心：AI 镜头"乱跑"或逻辑混乱，根因是提示词没写清「从哪、什么景别、跟谁」。本库补上 18 种运镜表缺失的「**镜头在人物与物品之间切换**」组合技法。

## 核心逻辑（三要素）

一个可用的镜头提示词必须同时写清三个要素：
1. **镜头位置/方向**：左侧、右侧、正面、后方、环绕、上移…
2. **景别**：近景、中景、全景、特写、大特写
3. **运动方式**：跟随、摇移、上移、前推、环绕…
4. **（切换对象时）结束落点**：切到谁/什么物品，最终画面停在何处

## 可直接套用的镜头提示词模板

| 镜头类型 | 模板 | 画面效果 |
| :--- | :--- | :--- |
| 人物跟随 | 镜头从{人物}左侧近景跟随拍摄{人物} | 在人物左侧近距跟随 |
| 摇移 | 镜头左摇+中景拍摄{人物} | 从右向左水平摇动，保持中景 |
| 环绕 | 镜头上移+向右环绕{人物}拍摄 | 上移同时围绕人物右绕 |
| 特写前推 | 镜头前推 | 推进聚焦手部/戒指等细节 |
| **切换对象** | 镜头从{人物}手部前推到{物品}，再向右环绕{物品} | 从人物手部切到物品并环绕 |

## 切换拍摄对象（本库核心，18种运镜表之外）

**用法**：人物动作和物品揭示要分开写，先人物后物品，用「前推→切换→环绕」把镜头从一个主体引导到另一个主体：

```
古风男子特写，抬手取下发间玉簪，镜头顺着他的手部动作前推，
画面焦点切换到玉簪（翠绿玉质，雕云纹），随后镜头向右环绕玉簪拍摄一周，
突出玉簪的细节与光泽。
```

```
刺客横刀而立，镜头从刀锋前推，画面焦点切换到刺客手腕上的铜制臂环
（磨损痕迹清晰），随后环绕臂环一圈，再拉回中景露出刺客冷厉目光。
```

## 使用规则

1. **镜头和运动绑定**：不写「跟随拍摄」，要写「从哪个方向 + 什么景别 + 跟随谁」。
2. **动作变化分层**：人物从坐→站起，镜头同步「上移+环绕」，提示词写清组合动作。
3. **切换要写终点**：从人物切到物品，必须写清「最终画面停在什么物体/景别」，防止镜头切到物品后又乱跑。
4. **服务叙事**：受规则21约束——物品揭示用于关键道具、伏笔、身份线索，禁止为炫技硬切。物品特写镜头通常紧跟该物品被台词/动作点名的瞬间。
5. **一镜一运镜**：切换对象仍算一个运镜（前推→环绕是同一镜头内引导，不算多运镜堆砌）。
