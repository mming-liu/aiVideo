# Seedance 2.5 运镜提示词

## 核心逻辑

AI视频的"镜头单调""视角混乱"，本质是提示词没有描述**拍摄视角和镜头运动**。四种视角覆盖所有场景需求。

---

## 四大类镜头视角提示词模板

### 1. POV视角（第一人称：身临其境）

**核心逻辑**：以第一人称视角呈现画面，让观众代入角色

**适用场景**：仙侠施法、战斗反击、探索互动、手持动作

**提示词模板**：
```
第一人称视角，手部特写，掌心凝聚红色能量，前方蓝色怪物扑来，镜头跟随手部动作快速移动，背景为草地山脉，冷色调光影，电影质感

第一人称视角，手持发光长剑，前方怪物被剑气击退，镜头随挥剑动作快速上挑，背景为荒野，暖色调光影，动态模糊效果
```

### 2. 鸟瞰视角（展示建筑景观的宏伟感）

**核心逻辑**：从高空向下拍摄，展现场景的宏大与层次

**适用场景**：仙侠门派、海上仙山、建筑群全景、战场俯拍

**提示词模板**：
```
高空鸟瞰视角，镜头从海面缓缓上摇，远处海浪翻涌，岸边矗立着多层古风楼阁，阳光穿过云层洒在建筑上，飞鸟掠过天空，暖金与深蓝交织的色调，电影质感

高空鸟瞰视角，镜头从云层中缓缓下移，下方是悬浮的古风建筑群，建筑之间有瀑布流淌，水面倒映着天空，冷色调光影，宏大壮观
```

### 3. FPV视角（穿梭机视角展示场景）

**核心逻辑**：以第一人称穿梭视角快速穿越场景，展现空间层次

**适用场景**：古风城镇、仙门秘境、爆炸场景、空间穿越

**提示词模板**：
```
FPV穿梭视角，镜头从古风城镇的上空快速俯冲，穿过密集的古建筑群，下方人群涌动，远处天空有爆炸火光，镜头随穿梭动作快速晃动，动态模糊效果，暖色调光影

FPV穿梭视角，镜头从仙门秘境的入口快速飞入，穿过悬浮的建筑和瀑布，周围有云雾缭绕，镜头随穿梭动作快速旋转，冷色调光影，奇幻感
```

### 4. ACT视角（展示战斗/动作场景）

**核心逻辑**：以第三人称视角呈现战斗动作，突出打击感与动态张力

**适用场景**：仙侠对战、游戏打斗、技能释放、暗器投掷

**提示词模板**：
```
ACT战斗视角，镜头跟随粉色狐耳女子的动作快速移动，她手持发光长剑向对面黑衣女子挥去，剑气击中地面产生红色裂痕，镜头随挥剑动作快速上挑，动态模糊效果，冷色调光影

ACT战斗视角，镜头从侧面拍摄，两人对峙，双方同时释放技能，能量碰撞产生爆炸，镜头随爆炸动作快速后退，动态模糊效果，暖色调光影
```

## 通用运镜关键词库

### POV视角（第一人称代入）
第一人称视角、手部特写、镜头跟随动作、动态模糊、身临其境、手持感

### 鸟瞰视角（高空俯拍）
高空向下、缓缓上摇、缓缓下移、建筑全景、宏大壮观、暖金/冷色调

### FPV视角（穿梭机穿越）
穿梭俯冲、快速晃动、动态模糊、空间层次、奇幻感、快速穿过

### ACT视角（战斗动作）
战斗跟随、挥剑动作、打击感、爆炸特效、动态模糊、快速旋转

### 通用运镜动作
镜头跟随、缓慢推进、快速拉出、环绕旋转、手持晃动、动态模糊

## 视角选择指南

| 场景类型 | 推荐视角 | 关键描述 |
|----------|----------|----------|
| 施法/发功 | POV | 第一人称、手部特写、能量凝聚 |
| 城市/门派全景 | 鸟瞰 | 高空俯拍、缓缓摇移、建筑群 |
| 空间穿越/追逐 | FPV | 穿梭俯冲、快速晃动、风吹效果 |
| 战斗/对决 | ACT | 战斗跟随、挥剑上挑、打击感 |
| 对话/情绪 | POV | 第一人称、面部特写、微表情 |
| 大军/战场 | 鸟瞰 | 高空俯拍、万军列阵、烟尘弥漫 |
