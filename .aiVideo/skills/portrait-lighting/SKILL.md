# 8种AI人像专业光位

## 核心问题

提示词只写"电影感""自然光"，AI 无法确定光从哪里来、投在脸上形成什么形状的阴影——导致人像光影平庸、没有故事感。光位必须写**具体灯位 + 画面特征 + 情绪效果**。

## 正确提示词结构

```
主光位置（相对人物/镜头）+ 软硬光性质 + 阴影形状特征 + 情绪词
```

## 8种光位速查表

| 光位 | 灯位要点 | 画面特征 | 情绪效果 | 适用 |
|------|----------|----------|----------|------|
| **正面顺光** | 主光在镜头正后方，与镜头光轴重合，接近人物眼睛高度 | 面部阴影极少，左右亮度一致，眼窝清晰不深陷，鼻下仅浅阴影 | 自然、稳定、亲和 | 日常、清新、温馨对白 |
| **前侧光** | 主光在人物左/右前方约30°，高于眼睛20-30°，中等面积柔光 | 靠光源侧额头颧骨明亮，鼻梁在另一侧留短柔阴影，暗侧眼睛保留细节 | 立体、经典、耐看 | 人物主镜头、商业感 |
| **蝴蝶光** | 主光在人物正前上方，水平角0°，高于眼睛35-45°，中等柔光 | 额头鼻梁双侧颧骨对称受光，鼻尖下短小居中蝴蝶形阴影，面颊下颌收紧 | 精致、优雅、高级 | 女角特写、唯美定格 |
| **伦勃朗光** | 主光在人物左前上方，水平约45°，高于眼睛30°，硬光 | 暗侧脸颊出现三角形亮区，明暗对比强、暗部留细节 | 深邃、神秘、有故事感 | 悬疑、男性角色、情绪戏 |
| **侧光** | 主光在人物正侧方（左或右），与人物成90°，硬光 | 面部一半亮一半阴影，明暗交界线清晰，轮廓硬朗 | 硬朗、冲突、有力量感 | 硬汉、对峙、黑白质感 |
| **逆光** | 主光在人物正后方，略高于头顶，硬光 | 正面在阴影中，头发肩膀身体边缘成明亮轮廓光，背景亮、人物分离 | 神秘、浪漫、氛围感 | 剪影、黄昏、离别、神圣 |
| **顶光** | 主光在人物正上方垂直向下，硬光 | 眼窝鼻下下颌阴影明显，面部轮廓深邃，压迫感 | 压迫、权威、神秘 | 反派、神明、高位者 |
| **底光** | 主光在人物正下方垂直向上，硬光 | 面部下方明亮、上方阴影，阴影反常向上生长 | 诡异、危险、邪恶 | 恐怖、反派、火光照脸 |

## 场景适配规则

- **清新/日常/温馨对白**：正面顺光、前侧光（如日常对白镜、温情镜头）
- **唯美/高级/定格**：蝴蝶光（女角特写、情感高潮定格）
- **悬疑/情绪/男性**：伦勃朗光（密谋、心理戏、刺客暗面）
- **硬汉/对峙/冲突**：侧光（打斗前对峙、审问、权力角力）
- **氛围/剪影/浪漫**：逆光（黄昏离别、月光下剪影、烛光烘托）
- **反派/权威/威慑**：顶光（高位者俯视、幕后主使）
- **恐怖/诡异/惊吓**：底光（火把从下照脸、井边、阴森反转）

## 落地到分镜 prompt 的写法

视频镜头与证件照不同，光位要配合**光源动机**（画面里出现真实光源）才不穿帮：

- 逆光 → "黄昏暖金逆光从画面右后方照射，勾勒杨旭肩背轮廓，正面没入暗部"
- 伦勃朗光 → "烛火主光在张十三左前上方45°（硬光），暗侧脸颊现三角形亮区"
- 顶光 → "天井顶光垂直泻下，眼窝与鼻下浓重阴影，压低镜头仰拍"
- 底光 → "篝火在人物正下方跳动，光影自下而上，面部下方明亮"

**关键**：光位要写进 prompt 的光影分层段落（主光/辅光/轮廓光），配合已有的
`色温量化`（5500K 等）与 `光源动机`（烛火/月光/灯笼/篝火）规则，禁止写
"自然光""柔和光线"这种无位置、无来源的模糊光。

## 情绪词组合技巧

光位确定后，用情绪词强化氛围（写进 color_tone / prompt 尾部）：

- 逆光 + 浪漫 → "剪影轮廓染上暖金，气氛缱绻"
- 伦勃朗 + 神秘 → "三角亮区在暗影中若隐若现，眼神深不见底"
- 顶光 + 权威 → "强光自头顶压下来，逼视感强烈"
- 底光 + 诡异 → "光芒反常向上，五官在阴影中扭曲"

## 镜头参数补充（可用但非必须）

85mm镜头、f/1.8光圈、浅景深、4K高清——已由全局渲染参数覆盖时不必重复堆砌。
