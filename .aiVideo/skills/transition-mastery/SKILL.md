## §1 转场技巧（10 种电影级转场）

### 正确提示词结构

`画面内容 + 镜头运动 + 光影变化 + 转场指令`

### 生成即衔接原则

1. **转场逻辑嵌入每段结尾**：每个分镜的 prompt 结尾直接写明转场方式
2. **动作重叠法**（最实用）：下一镜开头重复上一镜结尾动作
3. **视频延展法**：截取上一段视频结尾 3 秒作为下一段的参考帧（由 step02a 首尾帧+context_bridge 实现）
4. **镜头自含小剧情**：每个分镜设计为可完成的小剧情（起-承-合）
5. **参数锁死**：转场关键镜头加"保持角色面部、发型、服装不变"

### 转场时长规范

| 场景类型 | 转场时长 | 核心关键词 |
|----------|----------|------------|
| 打斗场景 | 0.2s | 冲击转场、快速跟拍、动作连贯 |
| 人物特写 | 0.3s | 模糊转场、镜头推近、节奏缓慢 |
| 场景切换 | 0.5s | 淡入淡出、镜头拉远、自然过渡 |
| 情绪递进/高光 | 1.0-1.5s | 推近匹配、空镜匹配、拉远揭示 |

### 10 种高级电影感转场

| 转场类型 | 提示词要点 | 适用场景 |
|----------|------------|----------|
| **空镜匹配转场** | 前后画面色彩/形状相似接力 | 风光、情绪向 |
| **过肩遮挡转场** | 前景人物掠过遮满画面，期间换空间 | 悬疑、剧情向 |
| **甩镜转场** | 人物转身+镜头甩动，运动模糊最强瞬间切入 | 动作、情绪爆发 |
| **推近匹配转场** | 持续推进至眼睛占满画面，切到下一场景的圆形灯光 | 情绪递进、高光 |
| **拉远揭示转场** | 从细节开始拉远至门框占满画面，切入门后场景 | 悬疑、揭秘 |
| **光线闪白转场** | 按下开关灯泡亮起闪白，消退后切到白天 | 时间跳转、回忆杀 |
| **物体擦拭转场** | 抹布擦桌面，抹布覆盖画面时切换 | 日常、剧情向 |
| **动作匹配转场** | 抬手关门的瞬间，切到另一场景中同样抬手关门的动作 | 平行叙事、时空跳转 |
| **焦点虚化转场** | 聚焦人物面部逐渐虚化，虚化完全时切入新场景 | 回忆、闪回 |
| **声画延续转场** | 结尾脚步声持续画面渐暗，脚步停下时切入新场景 | 悬疑、剧情向 |

### 题材 → 转场适配

- **悬疑/惊悚**：过肩遮挡、焦点虚化、声画延续
- **动作/追逐**：甩镜、动作匹配、光线闪白
- **文艺/伤感**：空镜匹配、拉远揭示、焦点虚化

### 场景判断触发词

- **打斗**：打斗、战斗、刺杀、攻击、挥刀、拔剑、跃出、冲刺
- **人物特写**：特写、近景、面部、眼神、表情、眼睛、嘴唇、手指、凝望
- **场景切换**：相邻镜头 scene 不同

### clip_transition 字段要求

- **必须填写**：禁止留空或仅写"硬切"
- **打斗场景**：必须包含"冲击转场"或"动作连贯"
- **特写场景**：必须包含"模糊转场"或"镜头推近"
- **场景切换**：必须包含"淡入淡出"或"自然过渡"

## §2 闪回配方（三套：温暖/创伤/幻觉）

### 核心原则

1. **闪回 ≠ 换色**：必须有完整视觉标识系统（色调+颗粒+柔边+光效+转场）
2. **与现实有明确分界线**：闪回段落首尾必须有进入/退出过渡
3. **情绪决定配方强度**：温馨=暖金轻颗粒；创伤=冷青重颗粒；幻觉=过曝+柔光
4. **人物面部仍可辨识**：不能为了"闪回感"把脸糊到认不出

### 配方 A：温暖回忆型（故友/往事/旧时光）

- **色调**：暖金褪色，饱和度降低 40-50%，偏琥珀色
- **质感**：轻微胶片颗粒
- **边缘**：边缘柔化晕染（非暗角）
- **光效**：柔光漫射，轻微过曝，阳光斜射光束
- **转场（进入）**：焦点虚化转场
- **转场（退出）**：叠化转场 + 缓慢清晰
- **prompt 模板**：
```
暖金色褪色回忆画面，整体饱和度偏低，偏琥珀色调，轻微胶片颗粒感，
边缘柔化晕染，柔光漫射，阳光斜射有光束感，画面有旧时光质感，
人物面部清晰可辨，服饰发型与现实段落一致
```

### 配方 B：创伤闪回型（噩梦/刺杀/血腥记忆）

- **色调**：冷青褪色，饱和度降低 50-60%，偏铁青/灰蓝
- **质感**：重胶片颗粒 + 轻微划痕感
- **边缘**：暗角压边（四周暗化，中心亮）
- **光效**：硬光高对比，明暗交界锐利
- **转场（进入）**：闪白/闪黑切入
- **转场（退出）**：快速抽离
- **prompt 模板**：
```
冷青色创伤闪回画面，低饱和高对比，偏铁灰色调，重胶片颗粒感，
四周暗角压边，硬光高对比明暗锐利，画面有破碎记忆的不安感，
人物动作剧烈但面部轮廓清晰，服饰色调以灰黑白为主
```
- **古风权谋**：血迹用"暗红/暗褐色"呈现，在低饱和画面里只保留一丝血色

### 配方 C：幻觉梦境型（中毒/濒死/意识模糊）

- **色调**：低饱和灰调 + 局部色偏（边缘偏冷中心偏暖）
- **质感**：极轻颗粒 + 轻微动态模糊
- **边缘**：重度柔化 + 渐隐入背景
- **光效**：柔光过曝，高光轻微 bloom
- **转场（进入）**：旋转虚化/螺旋模糊
- **转场（退出）**：溶解消散
- **prompt 模板**：
```
梦幻迷离的幻觉画面，低饱和灰调，边缘柔化如薄纱笼罩，
柔光过曝有 bloom 泛白感，轻微动态模糊仿佛意识飘忽，
人物轮廓清晰但边缘似融未融，整体有不真实的漂浮感
```

### 闪回镜头结构铁律

```
现实镜头（触发物：旧信物/一句话/一个身影）
  → 进入转场（焦点虚化/闪白，0.5-1 秒）
    → 闪回内容（2-4 个镜头，1.5-3 秒/镜，节奏偏快）
  → 退出转场（叠化/抽离，0.5-1 秒）
现实镜头（人物反应：惊醒/垂泪/握拳）
```

- **单镜时长**：1.5-3 秒（比现实镜头短，制造碎片式记忆感）
- **整段总时长**：5-10 秒（超 10 秒观众会出戏）
- **进入/退出转场**：各 0.5-1 秒

### 闪回触发物清单（古风题材）

| 触发物 | 示例 | 闪回内容 |
|--------|------|----------|
| 信物 | 玉佩/发簪/折扇/香囊/旧剑 | 赠予场景/故人身影 |
| 场景 | 旧宅院/荷塘/破庙/长街 | 当年发生的事 |
| 声音 | 箫声/琴声/脚步声/呼唤名 | 记忆中同一段声音的画面 |
| 气味 | 药香/酒香/熏香/血腥味 | 与气味关联的往事 |
| 伤痕 | 旧伤疤/心口伤/手上茧 | 受伤时的场景 |
| 人影 | 背影/侧影/相似衣着 | 认错人/想起故人 |

## §3 快慢变速节奏（五种模式）

### 核心原则

1. **节奏 = 快慢差**：没有快就显不出慢，关键动作前必铺相反节奏
2. **一镜一主导速度**：单镜头内只允许 **1 次变速切换**
3. **变速点 = 信息点**：变速切换的瞬间必须对应关键信息
4. **时长比例**：慢动作段占 20-30%，常速段占 70-80%

### 模式 1：快→慢定格（冲击强化型）

- **适用**：打斗命中瞬间、泪水滑落、真相揭露
- **时长分配**：前 60-70% 常速/快速 → 后 30-40% 慢动作/定格
- **模板**：
```
前 2 秒常速：刺客从画右飞身扑出，右手匕首直刺；
2-4 秒慢动作：刀锋刺入白袍心口的瞬间，时间凝滞，
衣袂翻飞的褶皱清晰可见，暗红洇痕在白袍上缓慢扩散
```

### 模式 2：慢→快爆发（蓄力释放型）

- **适用**：拔剑/跃起/运功、隐忍→爆发
- **时长分配**：前 50-60% 慢速/常速 → 后 40-50% 快速爆发
- **模板**：
```
前 2 秒慢动作：杨旭缓缓拔剑，剑身一寸寸出鞘，寒光顺着剑刃爬升；
第 2 秒突然加速：剑光一闪，长剑直刺画左刺客面门，速度极快带出动感模糊
```

### 模式 3：快慢交替（节奏切换型）

- **适用**：打斗连招（出招→命中→闪避→反击）、追逐跑酷
- **时长分配**：每个动作单元 1-2 秒，快 0.5s + 慢 0.5s 交替
- **限制**：仅限 `variation_type=large` 的高动作密度镜头（6-8s）
- **模板**：
```
0-1 秒快：刺客横划匕首，刀光一闪；
1-2 秒慢：杨旭侧身闪避，发丝被刀锋削断飘落；
2-3 秒快：杨旭反手一剑撩出；
3-4 秒慢：刺客后仰躲避，剑刃擦着鼻尖划过
```

### 模式 4：全局慢镜（情绪放大型）

- **适用**：高潮情绪戏（生离死别/告白/重逢）、关键揭示
- **限制**：每章最多 1-2 个全局慢镜头
- **模板**：
```
全程慢动作（0.5 倍速）：听香缓缓转过身，看见杨旭站在船头的瞬间，
瞳孔微微放大，手中的团扇悄然滑落，泪滴从眼眶溢出，
在空气中缓慢下坠，时间仿佛凝滞
```

### 模式 5：快进蒙太奇（时间压缩型）

- **适用**：赶路、准备/计划、时光流逝
- **实现**：由多个**短镜头剪辑组合**实现，每个短镜头一个动作/时间段
- **模板**：
```
（蒙太奇镜头组，共 4 秒，每镜 1 秒快进）
镜 A：晨光中，杨旭沿官道快步而行，身影拉长
镜 B：烈日下，杨旭翻过山坡，衣摆被风吹起
镜 C：黄昏中，杨旭走进小镇，背影融入人流
镜 D：夜色里，杨旭站在别庄门前，抬手叩门
```

### 变速触发词校验

- 慢动作/慢放/慢速 → 写清占比（前 X 秒/剩余时长）
- 快动作/快进/加速 → 写清哪段加速，与慢动作的切换点
- 定格/时间凝滞/瞬间 → 写清定格时长（如 1-3 秒）
- 变速/快慢/节奏变化 → 写清切换点对应的动作/事件

### 反例

- "全程慢动作"（没节奏对比）
- 一镜里快→慢→快→慢→快反复横跳（模型渲染不出来）
- 变速点没对应动作（变速无意义）
- 慢动作占 80%（成慢放 MV）
- 每章 10 个慢镜头（全高潮就没高潮）
- 打斗全程慢动作（违反打斗短镜快切铁律）
