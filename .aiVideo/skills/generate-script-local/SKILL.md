## 镜头词汇（来自 seedance-vocab-zh）

### 摄像机运动

| 运动 | 描述 | 用途 |
|------|------|------|
| 推镜 | `缓慢推镜` | 靠近主体、揭示细节 |
| 拉镜 | `镜头后拉` | 揭示空间、远离主体 |
| 跟拍 | `横向稳定跟拍` | 行进、追逐场景 |
| 固定 | `固定中景` | 对话、静止场景 |
| 环绕 | `弧形绕摄` | 展示主体、塑造立体感 |
| 手持 | `手持镜头，轻微晃动` | 紧张感、写实感 |
| 升降 | `缓慢升起` | 揭示空间层次 |

### 景别分配

- 摄像机 1（远景/全景/中景）：氛围渲染、场景建立
- 摄像机 2（中景/中近景/过肩）：人物互动、对话
- 摄像机 3（近景/特写/大特写）：情感高潮、细节强调
- **规则**：相邻镜头景别不得重复
- **规则**：至少 2 个镜头使用 medium 或 large variation

## 叙事节奏偏好

- **分镜数量**：N >= 6，最少 6 镜，覆盖全文
- **时长分配**：每条 duration 4-6 秒
- **旁白字数**：6 段 narration_segment 总字数 240-280 字
- **镜头过渡**（context_bridge，镜头 2-6）：描述上一镜结尾到本镜开头的空间/光影/时间过渡，30-60 字
- **角色汇总**（character_profile）：汇总所有出场人物外貌，50-80 字
- **首帧/尾帧描述**（ff_desc/lf_desc）：纯静态快照，无运动动词
- **运动描述**（motion_desc）：纯过程，无静态构图

## 分镜生成检查清单

生成每个镜头时，检查以下项：

- [ ] 景别与上一镜不重复
- [ ] 运动有具体物理描述（非抽象词）
- [ ] 光线有明确光源方向
- [ ] 角色外貌有具体五官描述（非"英俊"类词）
- [ ] 无空洞词（电影感/氛围感/高级感）
- [ ] 首帧/尾帧是静态描述
- [ ] motion_desc 是动态过程
- [ ] 时长与 narration 匹配
