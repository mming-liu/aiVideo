# AI短剧打斗四段式节奏框架

> 适配 aiVideo 古风真人竖屏打斗分镜。
> 核心：整段打斗（横跨多个镜头）按「对峙→攻防→反转→收尾」四段组织节奏，
> 用镜头长度、运镜速度、景别切换强化张力——**用镜头讲故事，而非单纯展示动作**。
> 与 combat-action（单镜招式/反馈/节奏）互补：那个管单镜动作本体，这个管整段节奏结构。

## 四段式节奏框架（直接套用）

### 1. 对峙阶段（开场，0-10s）
- 近景/特写快速交代双方状态，运镜偏**固定**，突出"一触即发"。
- 模板（1-2s/镜）：主角眼神近景固定 → 反派武器特写 → 全景战场环境建立。

### 2. 攻防阶段（主体，10-85s）
- **1-2 秒短分镜为主**，大量快速推镜/拉镜/跟拍，模拟高速打斗冲击力。
- 中间穿插 **3-4 秒中长镜头**展示关键招式（与 combat-action 短镜快切兼容：连贯招式仍短镜，展示性大招用中长镜）。

### 3. 反转阶段（大招/施法/蓄力，85-155s）
- **超长镜头（10s+）+ 慢镜头 + 环绕运镜** 展示施法/蓄力/大招过程，形成与前段快切截然相反的节奏反差（紧→松→紧）。
- **这是规则7"打斗一律短镜"的唯一例外**：蓄力/施法/大招镜允许长镜头慢放（3-5s 起，施法过程可更长），但必须是**特效/蓄力过程**而非连续招式堆叠。
- 运镜服务情绪：反派得势 = 高速后拉 + 仰拍；主角反击 = 环绕 + 推镜。

### 4. 收尾阶段（155-185s）
- 大远景/空镜拉长时间，突出战后平静与主角成长。
- 情绪升华：空镜叠化（极光/月夜/山水）转场，5-10s，暗示心境变化。

## 节奏控制三技巧

1. **快慢结合（紧-松-紧）**：高速打斗短镜快切，关键施法/蓄力长镜慢放。若打斗段全片都是 1-2s 短镜无任何反差，观众会疲劳、大招没有冲击。
2. **景别交替**：近景特写（表情/小动作）+ 全景大远景（战场/法术规模）交替，避免视觉疲劳。禁止连续多镜同景别堆打斗。
3. **运镜服务情绪**：镜头语言贴合角色状态——被动=高速后拉+仰拍（压迫感），反击=环绕+推镜（主角气势）。

## 蒙太奇多机位快切（走位/节奏感提升）

人物移动或连续打斗，组合四类镜头，切换时保持动作连贯即可丝滑：

```
① 全景视角（建立空间与人物关系）→ ② 中景侧面跟拍（跟随主体移动）
→ ③ 脚步特写（节奏/力度）→ ④ 脸部特写（情绪）
```

镜头切换时动作需连贯（上一镜结尾动作 = 下一镜开头动作），与动作重叠法一致。

## 可复用模板（AI 生成古风打戏直接套用）

1. **对峙开场**：近景固定拍主角眼神 → 特写反派武器 → 全景战场（1-2s/镜）
2. **攻防切换**：快速推镜拍武器碰撞 → 跟拍主角闪避 → 中景拍反派攻击落空（1s/镜）
3. **法术蓄力**：超长环绕镜头拍施法 → 特写法术特效 → 全景法术覆盖范围（3-5s/镜，慢镜）
4. **大招收尾**：闪白转场（1.5s）→ 大远景双方位置对比 → 特写主角收招（2-3s/镜）
5. **情绪升华**：空镜叠化 → 大远景主角背影 → 慢镜头环境变化（5-10s/镜）

## 适配 aiVideo 的注意点

- **反转长镜是规则7短镜铁律的例外**：仅在施法/蓄力/大招特效镜头使用，普通招式镜头仍 2-3s 短镜快切 + 0.2s 硬切。
- **闪白转场**：大招/雷击释放前用「黑场闪白」制造悬念，闪白时长约 1.5s，转场描述写进 prompt 结尾。
- **合规替换**：血→红、杀→击、死→倒；特效冲击波/气浪/火星四溅合规，禁止血腥细节。
- **竖屏适配**：环绕/全景多用纵向运动（上下移动）替代横向，主体保持在画面中央。
