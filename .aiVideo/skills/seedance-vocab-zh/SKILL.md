# seedance-vocab-zh

aiVideo 分镜生成用的中文镜头/灯光/运动词汇。

## 镜头词汇

| 功能 | 中文 | 英文 |
|------|------|------|
| 推镜 | `缓慢推镜` | slow push-in |
| 拉镜 | `镜头后拉揭示空间` | pull back to reveal |
| 跟拍 | `横向稳定跟拍` | stable lateral tracking |
| 平移 | `轨道平移` | slider/dolly |
| 定镜 | `固定中景` | locked medium shot |
| 特写 | `微距特写` | macro close-up |
| 仰拍 | `低角度仰拍` | low-angle shot |
| 俯拍 | `高角度俯拍` | high-angle shot |
| 过肩 | `过肩镜头` | over-the-shoulder |
| 环绕 | `弧形绕摄` | arc orbit |
| 手持 | `手持镜头，轻微呼吸晃动` | handheld with breathing sway |

## 景别词汇

| 中文 | 用途 |
|------|------|

| `中景` | 人物互动、对话 |
| `中近景` | 情绪传递 |

| `大特写` | 极致细节 |

## 紧凑模板

`@首帧锁定主体身份；@尾帧为最终画面目标；中间动作连续，不跳切。镜头：[镜头描述]。`

## Slop 陷阱

避免抽象词汇，改用物理元素：

| 套话 | 改写 |
|------|------|
| `电影感` | 写出景别、运镜、光源、调色：`宽幅远景，缓慢推镜，低角度暖阳` |
| `氛围感` | 写出物理元素：`薄雾、逆光轮廓、湿润地面反光` |
| `高级感` | 写出光线与材质：`柔和侧光、受控反光、金属拉丝纹理` |
| `震撼` | 写出造成震撼的那个画面对比或揭示 |
| `唯美` | 写出色彩、构图与光的具体行为 |
