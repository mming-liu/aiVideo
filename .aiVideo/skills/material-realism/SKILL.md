# AI材质写实化提示词

## 核心问题

AI生成的"塑料感""泡沫感"，本质是提示词只写了**物体名称**，没有描述**材质的物理属性、使用痕迹和环境影响**。

## 正确提示词结构

```
物体名称 + 物理材质（基底材质） + 表面细节（纹理/使用痕迹） + 环境状态（磨损/氧化/光影）
```

---

## 分场景提示词模板

### 1. 金属类（刀剑/铠甲/首饰）

**错误**：金属剑、金属铠甲、金戒指

**正确**：
```
手工锻造花纹钢刀，刀身有锻打纹理，边缘有磨损缺口，表面有铜绿氧化痕迹，刀身反光不均匀，带少量水渍和划痕

玄铁铠甲，铠甲表面有锈迹和战损划痕，金属光泽暗淡，边缘有磕碰缺口，暗处泛着冷冽寒光

黄金戒指，表面有氧化发黑痕迹，镶嵌宝石有磨损划痕，金属表面有使用留下的指纹油光
```

### 2. 织物类（仙侠纱袍/古装/披风）

**错误**：薄纱外袍、古风长袍

**正确**：
```
亚麻粗布底料，外层半透明纱质，纱线经纬交错，褶皱自然垂坠，布料有轻微做旧泛黄，边缘有磨损毛边

红色锦袍，丝绸面料有暗纹光泽，袖口有磨痕和脱线，衣摆有尘土痕迹，绣花有褪色泛白

白色披风，绸缎面有自然光泽，内部衬布有使用磨损，边缘有脱线，披风有自然褶皱
```

### 3. 玉石类（玉簪/翡翠/玉佩）

**错误**：玉石发簪、绿色戒指、玉佩

**正确**：
```
和田玉玉簪，质感半透明，内部有棉絮纹理，边缘透光，表面有轻微磨损划痕，带少量使用痕迹

冰种翡翠戒指，内部有棉絮纹理，表面有高透光泽，镶嵌部分有金属磨损痕迹，整体通透温润

青玉玉佩，表面有包浆光泽，边缘有磕碰缺口，内部有絮状纹理，背面有磨损指纹印
```

### 4. 透明/发光类（水晶法器/琉璃/宝石）

**错误**：水晶法器、琉璃剑、宝石

**正确**：
```
水晶法器，内部有交散光线，棱镜折射产生色散，表面有彩虹色各项异性高光，带少量划痕和灰尘，边缘有磨损

琉璃剑，内部有气泡纹理，表面有虹彩光泽，剑刃有细微磨损，整体半透明，光线穿过时形成彩虹光谱

红宝石，表面有刻面棱角光泽，内部有包裹体纹理，边缘有磨损划痕，宝石有自然光泽变化
```

### 5. 木质类（家具/武器/道具）

**错误**：木桌、木剑、书架

**正确**：
```
紫檀木桌，木材有自然年轮纹理，表面有包浆光泽，桌角有磨损痕迹，缝隙有灰尘堆积

木质剑柄，表面有刀剑摩擦光亮，柄缠布带有磨损脱落，木材有汗渍浸染变色，边缘有使用痕迹

竹简，竹片有自然纹理，颜色有陈旧泛黄，边缘有磨损卷曲，文字有褪色模糊
```

## 通用材质关键词库

### 金属类
锻打纹理、磨损缺口、铜绿氧化、反光不均匀、水渍划痕、锈迹、战损、寒光、磕碰

### 织物类
纱线经纬交错、褶皱垂坠、做旧泛黄、磨损毛边、暗纹光泽、脱线、尘土、脱色

### 玉石类
半透明、棉絮纹理、边缘透光、磨损划痕、使用痕迹、包浆、通透、温润、包裹体

### 透明类
交散光线、棱镜色散、彩虹高光、划痕灰尘、边缘磨损、气泡纹理、虹彩光泽、光谱

### 木质类
年轮纹理、包浆光泽、磨损痕迹、灰尘堆积、汗渍浸染、自然光泽、陈旧

### 通用表面状态
使用痕迹、磨损、氧化、水渍、灰尘、做旧、脱色、磕碰、划痕、包裹体
