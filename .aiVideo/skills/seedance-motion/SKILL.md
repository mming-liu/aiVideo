# seedance-motion

运动应使用物理动词和结果。运动应该在屏幕上可观察、在 clip 内计时、有明确主体或物体。

## 运动契约

每个镜头应声明：
- 动作主体
- 动作类型
- 力的大小
- 时机
- 物理结果
- 连续性要求
- 终点状态

## 强短语 vs 弱短语

| 类型 | 强 | 弱 |
|------|-----|-----|
| 表演 | `深吸一口气，紧握酒杯，目光不离` | `她很紧张` |
| 物理 | `水珠聚合后沿表面下滑` | `液体动态` |
| 动作 | `闪身躲过飞刀，左转站稳，举剑防御` | `打斗场面` |
| 环境 | `雨丝斜掠过逆光，水坑随脚步扩散` | 雨天氛围 |
| 布料 | `衣料随动作自然摆动` | 衣服飘动 |

## 时间结构

三段式结构：准备 → 动作 → 变化终点
- 0-2s：烛火稳定
- 2-4s：门开，火焰向内倾斜
- 4-6s：烟轨迹向走廊卷曲

## 物理优先

描述原因，让模型计算结果：
- 门关上 → 烛火向门方向倾斜（空气流动）
- 人物倒地 → 衣袂因惯性向前扬起
- 刀剑相交 → 火星向两侧溅射

## 脆弱细节稳定

手、脸、logo 在过多动作时会漂移：
- 唇同步时锁定相机
- 保持手部简单姿势
- 移动光线/环境而非核心主体

## 连续性

每个 clip 结尾应能成为下一个首帧：终点状态 = 下一镜起点
