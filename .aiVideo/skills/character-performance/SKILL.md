# 角色表演工艺全集

> 合并 2 个角色表演相关技能：restrained-emotion + voice-punctuation
> 适配 aiVideo 古风真人竖屏分镜。情绪越克制越动人，标点驱动语气。

---

## §1 克制情绪戏（微表情时间链）

### 核心原则

1. **克制基调优先**：哭戏不写"大哭"，写"无声哭/隐忍/眼含热泪但忍住不落"；失落不写"瘫坐捶地"，写"垂眼失神/发呆"
2. **微表情时间链**：一个克制情绪镜头 = 2-3 拍微表情，每拍一个具体面部细节，按时间先后逐拍递进。禁止只写一个情绪词、一个表情定住
   - 告别链：低头隐忍 → 眼含热泪 → 微笑释怀
   - 失落链：垂眼失神 → 眼尾泛红 → 低头苦笑
3. **禁止抽象情绪词**：克制情绪必须落到面部细节（眼眶泛红/嘴角紧闭/睫毛颤动/目光低垂）
4. **光影绑定情绪**：克制情绪配合低饱和暖/冷光、慢镜头/特写

### 克制情绪戏模板

```
[景别：近景/特写] [人物身份+神态]，[第 1 拍微表情：低头/垂眼/抿唇]，
眼眶泛红/睫毛颤动，[第 2 拍微表情：抬眼/泪光/嘴角变化]，
[第 3 拍微表情：释怀/苦笑/别过脸]，[慢镜头/固定特写]，[低饱和暖光/冷光+真实光源]
```

### 告别（释怀）示例

```
古风女子近景特写，欧式卷发披散，低下头压住情绪（嘴角紧闭，睫毛轻颤），
慢慢抬眼，眼中已蓄满泪光（眼泪将落未落），
随后浮起一个极浅的释怀微笑，转头望向远方。
慢镜头，暖金色余晖从画左斜照（逆光轮廓），画面安静克制。
```

### 失落示例

```
古风长发女子中近景，垂着眼失神（目光低垂无聚焦），
眼尾渐渐泛红（强忍住泪意），
低头苦笑一下，别过脸望向画右。
柔和冷调月光从画上方洒落，慢镜头，安静无声。
```

### 内心紧张示例

```
拟人化角色面部特写，呼吸微微加快（胸口起伏），眼神凝住警惕，
嘴角轻轻抿紧又松开，瞳孔微缩，
抬眼看向画左威胁来源。硬光顶灯制造压迫感，静止镜头。
```

### 落地要点

- 现有情绪可视化（_EMOTION_ACTION_MAP）已覆盖单情绪→单动作映射；本库补齐「**多拍递进**」这一层——克制情绪镜头至少 2 拍微表情
- 克制情绪词（隐忍/释然/失落/苦笑/哽咽/噙泪/别过脸）触发时，validation 检查是否同时满足：克制基调（无大哭/痛哭/猛摇头）+ 微表情链（≥2 个面部细节）+ 无抽象情绪词
- 禁止组合：克制情绪 + 大哭/暴怒大动作；哭泣镜头禁止"悲痛欲绝"类形容词堆砌

## §2 台词标点情绪语法

### 核心原则

**不改台词文字，用标点直接控制语气**——TTS/视频模型读标点决定停顿与升降调。
与规则 0（台词引用原文原句）兼容：文字保持原文，只对句末/停顿标点做情绪化处理。

### 三大基础技巧

| 情绪 | 标点 | 效果 | 示例 |
| --- | --- | --- | --- |
| 撒娇感 | 句尾加**波浪号** | 娇俏、软糯的撒娇语气 | 你是不是也有一点想我呀～ |
| 警告感 | 句尾加**感叹号** | 冰冷、有压迫感 | 别碰我的东西，听懂了吗！ |
| 思考感 | 停顿处加**逗号** | 真实说话卡顿、犹豫 | 等一下，我想，先确认一件事 |

### 情绪 → 标点组合对照

| 情绪类型 | 标点方案 | 发声要点 |
| --- | --- | --- |
| 难过/委屈 | 句尾「。」或「……」 | 语速放缓、尾音下沉、气息短促 |
| 愤怒/质问 | 句尾「！」 | 音量提高、字音加重、急促 |
| 惊讶/慌张 | 句尾「！」+ 停顿「，」 | 起音高、语速快 |
| 思考/迟疑 | 停顿处「，」 | 关键停顿拖长 |
| 温柔/安抚 | 句尾「～」或「。」 | 语速慢、语气软 |
| 紧张/压抑 | 停顿「…」+ 句尾「。」 | 气息不稳、尾音轻 |

### 长台词情绪组合

一条长台词可通过多组标点组合模拟复杂情绪变化：

- 撒娇 + 停顿：你先别走～我，我还有话说
- 警告 + 反问：再敢靠近一步！你试试看？
- 思考 → 决断：其实我，一直在想…好，那就这样定了！

### 适配 aiVideo 的注意点

- **不改台词文字**：narration_segment 仍是原文原句，只允许对句末标点（句号/感叹号/波浪号/省略号）和停顿逗号做情绪化调整
- **标点必须与情绪匹配**：警告类台词若用「。」会语气平淡；撒娇类若用「！」会像在吼
- **人物角色名必须保留**：说话人识别靠「角色名道：」前缀，标点情绪化只作用于冒号后的台词部分
