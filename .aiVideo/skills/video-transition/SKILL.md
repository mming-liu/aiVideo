# AI视频转场与长视频衔接技巧

## 核心问题

AI生成的"片段割裂感"，本质是提示词只写了**画面内容**，没有描述**转场方式、镜头运动、光影变化**；长视频被15秒时长限制切碎后，只靠首尾帧硬凑/故事板硬切，运动状态不一致、剧情割裂。

**正确提示词结构**：`画面内容 + 镜头运动 + 光影变化 + 转场指令`

## 生成即衔接原则（长视频丝滑衔接核心）

1. **转场逻辑嵌入每段结尾**：每个分镜的 prompt 结尾直接写明转场方式（如"画面冲击转场，转场时长0.2s"），让 AI 生成时就带衔接逻辑，替代后期硬拼首尾帧。
2. **动作重叠法（最实用）**：下一镜开头重复上一镜结尾的动作（如"上一镜收剑入鞘 → 本镜继续收剑入鞘的动作"），用动作承接自然开启新剧情，掩盖拼接点。
3. **视频延展法**：截取上一段视频结尾3秒作为下一段的参考帧，强化动作延续性（本流水线由 step02a 首帧/尾帧 + context_bridge 实现等价能力）。
4. **镜头自含小剧情**：每个分镜设计为15秒内可完成的小剧情（起-承-合），避免强行拆分长镜头。
5. **参数锁死**：转场关键镜头在 prompt 中加入"保持角色面部、发型、服装不变"锁定指令，降低衔接违和感。

## 转场时长规范

| 场景类型 | 转场时长 | 核心关键词 | 示例 |
|----------|----------|------------|------|
| **打斗场景** | 0.2s | 冲击转场、快速跟拍、动作连贯 | 两人打斗，镜头快速跟拍，画面冲击转场，转场时长0.2s |
| **人物特写** | 0.3s | 模糊转场、镜头推近、节奏缓慢 | 人物特写，镜头缓慢推近，画面模糊转场，转场时长0.3s |
| **场景切换** | 0.5s | 淡入淡出、镜头拉远、自然过渡 | 从室内切换到室外，镜头拉远，画面淡入淡出转场，转场时长0.5s |
| **情绪递进/高光** | 1.0-1.5s | 推近匹配、空镜匹配、拉远揭示 | 镜头持续推进，画面在匹配点切入新场景，转场时长1.5秒 |

## 10种高级电影感转场（莞夏）

核心是"视觉/听觉接力"——匹配前后镜头的形状、色彩、动作或声音，而非特效堆砌。

| 转场类型 | 可直接复制的AI提示词 | 适用场景 |
|----------|----------------------|----------|
| 空镜匹配转场 | 雨夜城市的霓虹倒影填满画面，镜头缓慢上移，画面自然切到同样蓝紫色调的玻璃幕墙与夜空，转场时长1.5秒 | 风光、情绪向内容，用色彩/形状相似性完成视觉接力 |
| 过肩遮挡转场 | 冷调室内对话，前景人物从镜头前掠过并短暂遮满画面；遮挡结束时，镜头已进入新的空间，人物动作与视线保持连续 | 悬疑、剧情向，制造节奏与悬念 |
| 甩镜转场 | 人物突然转身，镜头跟随动作快速横向甩动；在运动模糊最强的瞬间切入下一场景，保持相同的运动方向 | 动作、情绪爆发场景，加速叙事节奏 |
| 推近匹配转场 | 镜头持续向角色眼睛缓慢推进，画面在瞳孔占满画面时切到下一场景中同样居中的圆形灯光 | 情绪递进、高光时刻，把两段叙事连成连贯情绪动作 |
| 拉远揭示转场 | 从一只握着钥匙的手开始，镜头缓慢拉远，逐渐露出整扇门；当门框占满画面时，切入门后全新的房间场景 | 悬疑、揭秘类，营造期待感 |
| 光线闪白转场 | 角色按下开关，灯泡突然亮起，画面瞬间闪白；闪白消退后，切入同一房间的白天场景 | 时间跳转、回忆杀，强化时空变化 |
| 物体擦拭转场 | 镜头跟随抹布在桌面擦拭，抹布完全覆盖画面时，切入被擦拭干净的桌面新场景 | 日常、剧情向，自然切换空间 |
| 动作匹配转场 | 角色抬手关门，门即将关上的瞬间，切入另一个场景中同样抬手关门的动作 | 平行叙事、时空跳转，保持动作连贯性 |
| 焦点虚化转场 | 镜头聚焦角色面部，逐渐虚化背景；背景完全模糊时，切入新场景中同样虚化的背景，再缓慢清晰 | 回忆、闪回，营造氛围感 |
| 声画延续转场 | 前一段结尾的脚步声持续，画面逐渐变暗；脚步声结束时，切入新场景中人物停下脚步的画面 | 悬疑、剧情向，用声音衔接时空 |

### 题材 → 转场适配
- **悬疑/惊悚**：优先「过肩遮挡」「焦点虚化」「声画延续」
- **动作/追逐**：优先「甩镜」「动作匹配」「光线闪白」
- **文艺/伤感**：优先「空镜匹配」「拉远揭示」「焦点虚化」

## 场景判断规则

### 打斗场景触发词
打斗、战斗、格斗、刺杀、攻击、砍杀、挥刀、拔剑、跃出、冲刺、砍向、劈向

### 人物特写触发词
特写、近景、面部、眼神、表情、眼睛、嘴唇、手指、凝望、注视

### 场景切换触发词
（相邻镜头 scene 不同）

## clip_transition 字段要求

- **必须填写**：禁止留空或仅写"硬切"
- **打斗场景**：必须包含"冲击转场"或"动作连贯"
- **特写场景**：必须包含"模糊转场"或"镜头推近"
- **场景切换**：必须包含"淡入淡出"或"自然过渡"
