# seedance-antislop

删除隐藏视觉决策缺失的填充词。强 prompt 使用可观察的名词、动词、镜头运动、光源、声音提示和约束。
## 能见度测试

每个主要短语应能被相机拍摄、被测光表测量、在混音中可听到、或可观察为运动。
| 填充词 | 问它意味着什么 | 强替换 |
|-------|----------------|--------|  | cinematic | 什么让镜头有电影感？| `固定近景，暖色主光，冷色轮廓光` |
| epic | 规模或风险是什么？| `低角度远景，小人物对暴风雨墙` |
| beautiful | 什么颜色、纹理、光线？| `湿陶瓷上的珍珠高光，软窗光反弹` |
| dynamic | 什么在动，多快，结尾在哪？| `快速横移，停在标签上` |
## 六大空洞类

1. **空评价词** (`cinematic, epic, stunning`) - 转换为赚得这个词的那个可观察细节  2. **借用图片模型 token** (`8K, masterpiece, trending`) - 删除；质量和分辨率是设置，不是描述
3. **标签沙拉** (逗号分隔关键词) - 改写为拍摄简报散文
4. **否定空洞** (`no blur, no artifacts`) - 否定会召唤；描述存在的，而不是不存在的
5. **形容词堆叠** (三个同义词) - 选择唯一重要的细节
6. **感觉后缀词** (`电影感, 氛围感, 高级感`) - 说出感觉的物理原因

## 中文空洞词陷阱

| 套话 | 改写为 |
|------|--------|
| 电影感 | 写出景别、运镜、光源和调色 |
| 氛围感 | 写出薄雾、逆光轮廓、湿润地面反光 |
| 高级感 | 写出柔和侧光、干净背景、金属拉丝纹理 |
| 大片感 | 写出人群数量、镜头距离、建筑高度 |
| 质感 | 指明哪种质感：磨砂玻璃、丝绒吸光 |
| 震撼 | 写出造成震撼的那个画面对比或揭示 |
| 唯美 | 写出色彩、构图与光的具体行为 |
