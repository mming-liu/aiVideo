> 合并 5 个相机相关技能：situation-camera + advanced-camera-movement + focal-switch + shot-assembling + occlusion-layering
> 适配 aiVideo 古风真人竖屏分镜。运镜服务叙事，一镜一运镜。

## §1 19 种情景剧运镜速查

| 运镜类型 | 核心用法 | 情绪效果 | 适用场景 |
|----------|----------|----------|----------|
| 推镜（情绪聚焦） | 缓慢推近人物面部特写 | 强化情绪、聚焦内心 | 情绪爆发、秘密揭露、告白 |
| 拉镜（氛围烘托） | 快速拉远到全景 | 凸显孤独、宏大感 | 离别、失去、史诗场景 |
| 跟镜（代入感） | 平稳跟随、保持固定距离 | 增强代入感 | 追逐、跟踪、日常行动 |
| 摇镜（空间展示） | 从左到右/从上到下摇摄 | 交代场景、营造氛围 | 房间介绍、悬疑场景 |
| 移镜（层次感） | 横向移动+前景遮挡 | 增强空间深度 | 对话、互动、多人场景 |
| 甩镜（节奏加速） | 快速甩动 | 紧张、急促、反转 | 打斗、追逐、剧情反转 |
| 环绕镜（名场面） | 360°匀速环拍 | 打造高光、强化气场 | 主角出场、高光时刻、仪式感 |
| 低角度仰拍（压迫感） | 从下往上仰拍 | 权威、压迫、英雄主义 | 反派出场、权力场景 |
| 高角度俯拍（无助感） | 从上往下俯拍 | 无助、孤独、被监视 | 悬疑、惊悚、弱势角色 |
| 过肩镜（对话感） | 从一人肩膀后方拍另一人 | 增强对话真实感 | 双人对话、对峙 |
| 正反打镜（对话节奏） | 交替拍摄对话双方 | 加快对话节奏 | 多人对话、争吵、谈判 |
| 手持镜（真实感） | 模拟手持轻微晃动 | 纪实感、紧张感 | 纪实、悬疑、紧急场景 |
| 变焦镜（视觉冲击） | 突然放大/缩小 | 强化震惊、顿悟 | 反转、发现线索 |
| 空镜转场 | 拍摄无人物空镜 | 舒缓节奏、过渡 | 时间跳转、场景切换 |
| 慢动作镜 | 放慢动作 | 强化感动、震撼 | 告白、离别、高光时刻 |
| 快动作镜 | 加快动作 | 紧张、急促、喜剧 | 追逐、搞笑、紧急 |
| 长镜头 | 连续拍摄不剪辑 | 叙事连贯、真实感 | 复杂动作、长对话、纪实 |
| 分割画面镜 | 分割画面同时展示 | 平行事件、对比 | 双线叙事、悬疑 |
| 偷窥视角镜 | 门缝/窗格/花丛后拍摄 | 窥视、密谋、悬疑 | 秘密交谈、谈判 |

### 情绪 → 运镜 快速决策

| 剧情情绪 | 首选运镜 | 备选 |
|----------|----------|------|
| 情绪爆发/秘密揭露/告白 | 推镜 | 慢动作、变焦 |
| 离别/失去/史诗感 | 拉镜 | 俯拍、长镜头 |
| 追逐/跟踪/紧急 | 跟镜 | 手持、甩镜 |
| 反派出场/权力/压迫 | 低角度仰拍 | 环绕镜 |
| 悬疑/惊悚/被监视 | 高角度俯拍 | 摇镜、空镜、偷窥视角 |
| 双人对话/对峙/谈判 | 过肩镜 | 正反打、移镜 |
| 秘密交谈/密谋 | 偷窥视角镜 | 过肩镜 |
| 打斗/追击/反转 | 甩镜 | 手持、快动作 |
| 主角高光/仪式感 | 环绕镜 | 低角度仰拍、慢动作 |
| 普通对话/日常 | 固定机位 | 移镜、跟镜（小幅） |

### 适配要点

- **一镜一运镜**：禁止堆叠多段运镜，变化交给相邻镜头的 clip_transition
- **打斗/追杀**：2-3 秒短镜 + 0.2s 硬切，甩镜/手持/快动作优先
- **竖屏 9:16**：环绕/移镜/甩镜多用纵向运动，画面主体保持中央
- **过肩/正反打**：跨相邻镜头实现，A 镜从 A 肩后拍 B，B 镜从 B 肩后拍 A
- **偷窥视角**：前景遮挡物（门缝/窗格/花丛/屏风/墙角）留虚影，人物在中景交谈
- **空镜转场**：遵守空镜约束（画面无人物），用淡入淡出
- **慢动作/快动作**：写明"前 X 秒：动作；X-Y 秒：慢动作/快进；剩余：常速"分段
- **固定机位是基础**：普通对话/静态镜头默认固定

## §2 高级运镜（基础→带特效细节升级）

| 基础运镜 | 高级提示词 | 效果特点 |
|----------|------------|----------|
| 推镜头 | 侵入式推进+轻微变焦扭曲 | 镜头有"压迫感"地靠近主体 |
| 拉镜头 | 反向变焦后拉+视差空间剥离 | 凸显空间空旷与孤独感 |
| 摇镜头 | 极速鞭甩+动态残影捕捉 | 紧张、急促的动作感 |
| 移镜头 | 斯坦尼康横移+前景遮挡 | 平稳横移+层次感 |
| 跟镜头 | POV视角+动态构图重构 | 第一人称主观跟随 |
| 甩镜头 | 暴力轴向撕裂+画面畸变拉伸 | 强化反转、高光视觉冲击 |

### 场景触发词

- **悬疑/惊悚**（侵入式推进、暴力轴向撕裂）：对峙、逼近、杀意、阴影、陷阱、危机、潜入、埋伏
- **动作/追逐**（极速鞭甩、POV视角跟拍）：打斗、刺杀、追击、拔剑、冲刺
- **文艺/伤感**（反向变焦后拉、斯坦尼康横移）：离别、孤独、回忆、凝望、转身离去

### 使用规则

1. 直接套用：把"基础运镜词"替换成"高级提示词"
2. 强特效运镜只用于反转、对峙、高光；对话/特写/空镜优先固定机位
3. 提示词后可补 `4K 高清、电影感、动态模糊` 等画质词

## §3 切换拍摄对象（人物→物品）

### 核心逻辑（三要素）

一个可用的镜头提示词必须同时写清：**镜头位置/方向** + **景别** + **运动方式** + **（切换对象时）结束落点**。

### 切换对象模板（18 种运镜表之外的补充）

**用法**：人物动作和物品揭示要分开写，先人物后物品，用「前推→切换→环绕」把镜头从一个主体引导到另一个主体。

```
古风男子特写，抬手取下发间玉簪，镜头顺着他的手部动作前推，
画面焦点切换到玉簪（翠绿玉质，雕云纹），随后镜头向右环绕玉簪拍摄一周，
突出玉簪的细节与光泽。
```

```
刺客横刀而立，镜头从刀锋前推，画面焦点切换到刺客手腕上的铜制臂环
（磨损痕迹清晰），随后环绕臂环一圈，再拉回中景露出刺客冷厉目光。
```

### 使用规则

1. 镜头和运动绑定：写「从哪个方向 + 什么景别 + 跟随谁」
2. 切换要写终点：从人物切到物品，必须写清最终画面停在何处
3. 服务叙事：物品揭示用于关键道具/伏笔/身份线索，禁止为炫技硬切
4. 一镜一运镜：前推→切换→环绕是同一镜头内引导，不算多运镜堆砌

## §4 镜头组接逻辑

### 四大基础剪辑原则

| 原则 | 含义 | 分镜要求 |
|------|------|----------|
| **动作匹配剪辑** | 上镜结尾动作 = 下镜开头动作 | 相邻镜头动作延续点必须标注 |
| **方向匹配剪辑** | 视线/运动方向不能乱 | 画左/画右锚定并校验连续性 |
| **位置匹配剪辑** | 人物构图位置统一 | 切景别后位置不变 |
| **情绪匹配剪辑** | 紧张用快切，悲伤用长镜 | 切换服从情绪节奏 |

### 180° 轴线规则（最高频避坑）

两个对话人物之间虚拟一条轴线，摄像机只能在轴线一侧拍摄。越轴后果：人物左右朝向颠倒，观众分不清谁在说话。

**可越轴的三情形**：
1. 插入空镜
2. 人物发生大幅度转身
3. 中间插入特写镜头

### 同一场景内切换

- 全景交代环境 → 中景交代互动 → 近景/特写给细节
- **禁止**：特写直接切大远景（中间缺过渡，观感割裂）

### 转场逻辑

- **硬切**：同场景、人物动作连贯，占绝大多数镜头
- **技巧转场**（叠化/闪白）：只用于时空跳转、回忆、时间流逝，禁止每镜都加

### 节奏公式

1. **冲突打斗**：1-2s/镜，硬切，景别快速切换
2. **双人对话**：2-4s/镜，正反打，不频繁乱切特写
3. **抒情/回忆/氛围**：4-6s+/镜，叠化转场
4. **禁忌**：全篇统一 1 秒 1 镜，文戏也疯狂快切，观众疲劳

### AI 容易犯的错误

1. 人物看向左边，下镜头被看对象出现在左边（视线方向错误）
2. 对话正反打随意越轴，角色左右来回翻转
3. 特写直接跳大远景，无过渡
4. 上镜向右走，下一镜向左走（运动方向冲突）
5. 每个镜头都加闪白、叠化转场

### 分镜字段要求

- 相邻镜头锚定人物朝向（画左/画右），同场景相邻镜头朝向不能翻转
- 景别切换幅度 ≤2 级（禁止特写↔大远景直接跳）
- `clip_transition` 默认 `hard_cut`（同场景硬切）
- 打斗短镜头、对话长镜头，禁止全部 1 秒 1 镜

## §5 前后遮挡逻辑（防穿模）

### 遮挡分层规则

AI 难从单张正视构图推断前后关系，必须在 prompt/ff_desc/lf_desc 主动写明「什么遮挡什么、遮挡到什么程度」。

1. **前景/中景/后景三层划分**：写明人物空间层位（前景围栏/中景人物/后景楼阁）
2. **写清"什么遮挡什么"**：
   - 「二楼走廊的木质围栏遮挡住女主的膝盖以下部位」
   - 「前景路人走过时短暂遮挡住女主的上半身」
   - 「门窗框遮挡住刺客的半张脸」
3. **避免只写遮挡不写程度**：禁止笼统"人物在围栏后"，要写遮挡到哪个部位

### 走位前后关系（多人互动）

- 多人互动明确人物前后位置：「路人从画面左侧走过，行进过程中短暂遮挡住女主」
- 遮挡结束后人物要**重新完整出现**：「路人走过遮挡结束后，女主完整重新出现」
- 前后位置必须与动线一致：先写动线（从哪走到哪），再写遮挡发生点

### 复合空间结构（一镜到底/大场景）

跨空间长镜头需在 prompt 写清空间层次推进：
```
镜头随人物走出包间（中景，门框在前景掠过遮挡人物）→ 沿二楼走廊前行
（前景围栏遮挡人物膝下）→ 下楼梯（俯拍，楼梯扶手遮挡下半身）→
一楼大堂（全景，柱子/屏风形成层次）
```

### 适配要点

- 遮挡不得遮住对话口型：有对话的镜头，遮挡物不得遮住说话人嘴部
- 空镜/无人镜头不适用遮挡规则
- 遮挡是空间关系，不涉及敏感内容
