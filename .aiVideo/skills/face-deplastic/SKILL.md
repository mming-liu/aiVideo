# AI人物去塑料感提示词（5XL-AI 整理）

## 核心问题

AI 人像的"塑料脸/硅胶感/过度磨皮"，本质是 prompt 只写了"皮肤好/光滑"，没有写**毛孔、红润、明暗、颗粒**四个反塑料要素。

一句话概括：**「有毛孔 + 有红润 + 有明暗 + 有颗粒」**。

## 基础核心提示词（面部特写必带）

```
可见毛孔细纹，自然红润感，面部要有明暗变化，不要均匀受光，有光影颗粒，灰尘噪点，不要干净无层次
```

## 强化补充提示词（按需叠加）

**皮肤细节类**：
```
真实皮肤纹理，轻微油光质感，细小汗毛，少量面部小痣，真实唇纹，眉毛根部细节
```

**光影结构类**：
```
侧光照明，柔和明暗过渡，苹果肌自然起伏，脸颊阴影层次，鼻翼到脸颊真实过渡，不要过度磨皮，不要完美对称
```

**氛围质感类**：
```
自然窗光，轻微呼吸感，眼神自然停留，不要脸颊一整片发亮，不要夸张五官，不要塑料皮肤
```

## 古风适配完整示例（面部特写）

```
写实古风真人，9:16竖屏，面部特写。可见毛孔细纹，自然红润感，面部要有明暗变化，
不要均匀受光，有光影颗粒，灰尘噪点，不要干净无层次。真实皮肤纹理，轻微油光质感，
细小汗毛，侧光照明，柔和明暗过渡，苹果肌自然起伏，脸颊阴影层次，鼻翼到脸颊真实过渡，
冷月清辉勾勒轮廓，不要过度磨皮，不要完美对称，电影感质感。
```

## 使用范围（重要）

- **仅面部特写镜头/面部特写肖像**注入完整去塑料段（毛孔/红润/明暗/颗粒）
- **普通镜头/全身镜头**不注入完整段（避免 prompt 冗余）——全身已有基础"真实皮肤纹理/毛孔"
- 与脸型库配合：先选脸型（[[face-shapes]]）定轮廓气质，再加去塑料段定皮肤真实感
