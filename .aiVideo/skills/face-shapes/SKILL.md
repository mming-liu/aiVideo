# AI人物脸型提示词库（5 种脸型）

## 核心问题

AI 生成的同框多人/多镜头角色，脸型容易漂移变脸。给每个角色在 `static_features` 里**锁定一个脸型词**（跨章一致），肖像/首帧/视频 prompt 全部用它，锁脸防变脸。

## 脸型速查对照表

| 脸型 | 核心关键词 | 气质 | 适配角色 |
| --- | --- | --- | --- |
| 猫系脸 | 细长眼、眼尾上挑、清冷警觉、小巧脸型 | 冷艳疏离、轻微攻击性 | 刺客/杀手/心思深沉的女角 |
| 鹿系脸 | 大而清澈的眼、湿润眼神、饱满苹果肌 | 温柔无辜、清纯 | 白月光女主、弱质/被保护者 |
| 狐系脸 | 眼尾明显上挑、尖下巴、狡黠眼神 | 妩媚危险、聪明精明 | 妖妃/宠姬/反派美人、心机女角 |
| 天鹅脸 | 修长脸型、高鼻梁、清晰下颌线 | 优雅高级、端庄 | 大家闺秀、权贵之女、名门正妻 |
| 雀斑脸 | 雀斑、自然皮肤、浅色眼睛、野生感 | 清冷文艺、真实素颜 | 山野/村姑/异族少女、质朴配角 |

## 气质 → 脸型映射（角色提取时按此选型）

- **猫系脸** → 刺客、杀手、心思深沉的女性（细长眼/眼尾上挑/清冷警觉）
- **鹿系脸** → 白月光女主、弱质、被保护者（大而清澈的眼/湿润眼神/温柔无辜）
- **狐系脸** → 妖妃、宠姬、反派美人、心机女角（眼尾上挑/尖下巴/狡黠/魅惑）
- **天鹅脸** → 大家闺秀、权贵之女、名门正妻（修长脸型/高鼻梁/清晰下颌线/贵气）
- **雀斑脸** → 山野、村姑、异族少女、质朴配角（自然雀斑/真实素颜/野生感）

## 跨章一致（最高优先级）

- **脸型词必须写入角色 `static_features`**（如 `鹿系脸，大而清澈的眼睛，鹅蛋脸，黑发挽髻`），CharacterBank 首次锁定不变
- 每章肖像、首帧、视频 prompt 引用同一脸型词，禁止每章换脸型
- 与去塑料段配合：先选脸型（[[face-deplastic]]），再加皮肤真实感
