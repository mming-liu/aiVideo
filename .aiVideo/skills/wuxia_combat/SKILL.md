## 核心技巧

### 打斗特效三诀窍
1. **定死动作速率** — 明确每个动作的时间节点
2. **穿插多视角切换** — 特写→中景→全景循环
3. **叠加动态残影效果** — 增强视觉冲击力

### 武器光效关键词库

| 武器 | 光效关键词 |
|------|-----------|
| 剑 | 冰金色轨迹、气浪炸裂、冰封碎裂、百米光弧 |
| 琴 | 金色光粒、水墨粒子、环形光效、光剑飞出 |
| 刀 | 红色残影、火花四溅、金属冷光、刀光斩击 |
| 枪 | 粉色光效、紫色光效、光盾展开、光效炸开 |

### 时间分段格式（强制）

当镜头时长超过8秒时，必须分时间段描述：
```
前3秒：动作描述
3-8秒：动作继续
8-12秒：动作高潮或结束
```

## 适配提示

### 转换为竖屏9:16
- 保持镜头在画面中央区域
- 强调人物面部特写
- 使用纵向运动（上下移动）替代横向

### 古风适配
- 兵器改为冷兵器（剑/刀/枪/琴）
- 背景使用中式建筑/山水/竹林
- 色调以青/金/红/黑为主

### 时长适配
- 每个分镜控制在 3-6 秒
- 快速斩击动作 1-2 秒
- 复杂动作序列 4-6 秒
