# Seedance 镜头工艺全集

> 本文件合并 13 个 seedance-* 技能为统一参考手册。
> 规则实现仍在 `prompts.py`（PROMPT_TEMPLATE）和 `validation.py`（校验器），本文件提供词汇和参考。

---

## §1 镜头与运镜

### 1.1 镜头契约

每个镜头应声明：

| 字段 | 选项 |
|------|------|
| 景别 | extreme wide / wide / medium wide / medium / medium close-up / close-up / extreme close-up |
| 角度 | eye-level / low angle / high angle / overhead / profile / over-shoulder |
| 相机支撑 | locked-off / handheld / slider / dolly / crane / gimbal |
| 运动 | push-in / pull-back / lateral track / orbit / pan / tilt / reveal |

### 1.2 景别词汇（中/英）

| 中文 | 英文 | 用途 | 注意 |
|------|------|------|------|
| 远景定场镜头 | extreme wide | 规模、到达、环境 | 人脸小，logo 会漂移 |
| 全景 | wide | 动作、舞蹈、行列 | 动作简单可读 |
| 中景 | medium | 对话、产品使用 | 角色广告好选择 |
| 中近景 | medium close-up | 情绪传递 | — |
| 近景 | close-up | 情感、表情、唇同步 | 相机稳定 |
| 特写 | extreme close-up | 材质、食品、关键物体 | 避免大动作 |
| 四分之三侧脸 | three-quarter | 塑造立体感 | — |

### 1.3 运动语法

| 运动 | 英文 | 用途 |
|------|------|------|
| 固定 | locked-off | 唇同步、连续性锚点 |
| 推镜 | dolly/push-in | 发现、顿悟、亲密感 |
| 横移 | lateral track | 行进、前景层穿过 |
| 环绕 | orbit | 庄重主体、hero shot |
| 摇镜 | pan/tilt | 横向/纵向摇动 |
| 手持 | handheld | 真实感或紧张感 |
| 升降 | crane up/down | 揭示空间层次 |

### 1.4 四大视角模板（Seedance 2.5）

| 视角 | 核心逻辑 | 适用场景 |
|------|----------|----------|
| **POV**（第一人称） | 代入角色，手部特写+镜头跟随动作 | 施法/发功、探索互动、对话情绪 |
| **鸟瞰**（高空俯拍） | 展示宏伟感与层次 | 城市/门派全景、大军/战场 |
| **FPV**（穿梭机） | 快速穿越场景，空间层次 | 空间穿越/追逐、爆炸场景 |
| **ACT**（战斗跟随） | 第三人称呈现打击感 | 战斗/对决、技能释放 |

**视角关键词库**：
- POV：第一人称视角、手部特写、镜头跟随动作、动态模糊、身临其境
- 鸟瞰：高空向下、缓缓上摇/下移、建筑全景、暖金/冷色调
- FPV：穿梭俯冲、快速晃动、动态模糊、空间层次
- ACT：战斗跟随、挥剑动作、打击感、爆炸特效、快速旋转

### 1.5 连续性规则

- 保持同一 wardrobe、道具、光线方向、视线
- 每个 clip 结尾应能成为下一个首帧

## §2 光线与色温

### 2.1 光线契约

每个镜头应声明：主光源方向、色温、阴影行为、反射行为、是否有过渡。

### 2.2 光源词汇

| 类型 | 中文 | 用途 |
|------|------|------|
| 实用灯 | 暖色烛光 / 暖色实用灯 | 古风室内、温馨氛围 |
| 窗光 | 柔和窗光 | 自然主义、生活场景 |
| 月光 | 冷色月光 / 冷色月光轮廓光 | 夜晚、孤独、侠客 |
| 轮廓光 | 冷蓝月光轮廓光 | 分离主体 |
| 体积光 | 体积光穿过薄雾 | 戏剧性空气感 |
| 局部光 | 烛火局部光影 | 古风暗调、重点照明 |
| 逆光 | 逆光剪影 | 神秘感、仪式感 |
| 反射光 | 湿润地面反射 | 夜景地面 |

### 2.3 情绪 → 光源转换

| 情绪 | 改写为光源 |
|------|-----------|
| 温暖 | 暖色烛光、橙红灯笼 |
| 孤独 | 冷蓝月光、远景单灯 |
| 紧张 | 侧逆光、晃动阴影 |
| 浪漫 | 柔和窗光、花瓣散落 |

## §3 运动描述

### 3.1 运动契约

每个镜头应声明：动作主体、动作类型、力的大小、时机、物理结果、连续性要求、终点状态。

### 3.2 强短语 vs 弱短语

| 类型 | 强 | 弱（避免） |
|------|-----|-----------|
| 表演 | 深吸一口气，紧握酒杯，目光不离 | 她很紧张 |
| 物理 | 水珠聚合后沿表面下滑 | 液体动态 |
| 动作 | 闪身躲过飞刀，左转站稳，举剑防御 | 打斗场面 |
| 环境 | 雨丝斜掠过逆光，水坑随脚步扩散 | 雨天氛围 |
| 布料 | 衣料随动作自然摆动 | 衣服飘动 |

### 3.3 时间结构（三段式）

准备 → 动作 → 变化终点：
```
0-2s：烛火稳定
2-4s：门开，火焰向内倾斜
4-6s：烟轨迹向走廊卷曲
```

### 3.4 物理因果优先

描述原因，让模型计算结果：
- 门关上 → 烛火向门方向倾斜（空气流动）
- 人物倒地 → 衣袂因惯性向前扬起
- 刀剑相交 → 火星向两侧溅射

### 3.5 脆弱细节稳定

手、脸、logo 在过多动作时会漂移：唇同步时锁定相机、保持手部简单姿势、移动光线/环境而非核心主体。

### 3.6 运动词汇（中文）

| 中文 | 用途 |
|------|------|
| 脚步带动薄雾扩散 | 行走场景 |
| 水珠聚合后沿表面下滑 | 液体运动 |
| 缓慢转头并停住 | 转身静止 |
| 衣料随动作自然摆动 | 服装动态 |
| 金色粒子升起后消散 | 魔法效果 |

## §4 角色一致性

### 4.1 角色契约

同框每人固定角色名（禁代词）；每人一个可观察行为，写明终点。

### 4.2 三档动作层级（多人同框铁律）

1. **持续微动作**：呼吸/眨眼/肩部轻动/发丝/目光漂移。非焦点角色默认档。
2. **一个聚焦反应**：只有 1 人获得一次带时间窗的小反应（如"听香嘴角抬起，目光停顿半秒"）。
3. **大动作默认禁止**：多人同框不安排站起/转身/行走/拾物，除非是本镜唯一节拍。

### 4.3 手与脸稳定

复杂调度先坏手和脸。手可见但简单、对话避免摸脸、唇同步锁相机。

### 4.4 表情 = 可观察行为

不写"惊恐"→ 写"双眼睁大、嘴唇微张、眉头抬起"。

## §5 导演意图

### 5.1 一镜一意图

写镜头前先答——"这镜要让观众感到什么"。意图定下后，景别/机位/运镜/光/表演/声音全部指向它。

### 5.2 潜台词 = 言行矛盾

最强节拍是"嘴上说一套、身体说另一套"——同意却后退、微笑却握紧杯。

### 5.3 一个手势承载转折

每镜给主角 1 个可拍摄的具体手势承载转折；短镜 1 个手势足够。

---

## §6 首尾帧衔接

- **ff_desc 是给图片模型的**：只写静态画面、不写图片外信息
- **lf_desc 是最终画面目标**：下一镜首帧的起点
- **中间动作连续，不跳切**
- 上一镜 lf 承接的状态不重放（已在上一镜发生）
- 本镜只执行本镜的动作
- 终点状态 = 下一镜起点

## §7 反空洞词（Anti-Slop）

### 7.1 能见度测试

每个主要短语应能被相机拍摄、被测光表测量、在混音中可听到。

### 7.2 六大空洞类

1. **空评价词**（cinematic/epic/stunning）→ 转换为赚得这个词的可观察细节
2. **图片模型 token**（8K/masterpiece/trending）→ 删除；质量和分辨率是设置不是描述
3. **标签沙拉**（逗号分隔关键词）→ 改写为拍摄简报散文
4. **否定空洞**（no blur/no artifacts）→ 否定会召唤；描述存在的
5. **形容词堆叠**（三个同义词）→ 选择唯一重要的细节
6. **感觉后缀词**（电影感/氛围感/高级感）→ 说出感觉的物理原因

### 7.3 中文空洞词 → 物理元素

| 套话 | 改写为 |
|------|--------|
| 电影感 | 写出景别、运镜、光源和调色 |
| 氛围感 | 薄雾、逆光轮廓、湿润地面反光 |
| 高级感 | 柔和侧光、干净背景、金属拉丝纹理 |
| 大片感 | 人群数量、镜头距离、建筑高度 |
| 质感 | 指明哪种：磨砂玻璃、丝绒吸光 |
| 震撼 | 写出造成震撼的那个画面对比或揭示 |
| 唯美 | 写出色彩、构图与光的具体行为 |

### 7.4 紧凑模板

`@首帧锁定主体身份；@尾帧为最终画面目标；中间动作连续，不跳切。镜头：[镜头描述]。`

## §8 内容安全重写

**意图修复而非绕过**：只修复假阳性（因过度过滤而被阻止的良性制作内容），不帮助真正禁止的内容。

### 安全重写模式

| 意图 | 安全方向 |
|------|----------|
| 冲突 | 编排的对打动作节拍，无图形伤害 |
| 后果 | 非图形化困境，破损服装，散落道具 |
| 悬念 | 阴影暗示的威胁，锁着的门，低光 |
| 武器状道具 | 在编排动作场景中安全处理的道具 |
| 恐怖情绪 | 诡异氛围，闪烁实用灯，画面外声音 |

## §9 音频

### 9.1 唇同步稳定

对话镜头锁相机、台词一句一呼吸、避免转头/大面部动作/忙碌手势，口型优先。

### 9.2 一镜一说话人

双人轮替"先 A 说…停顿…B 答"保持镜头稳定；避免同镜多人同时开口。

### 9.3 音效具体命名

audio_cue 写"杯落桌面/刀鞘轻响"而非"声音"；中文普通话唇同步最强，台词短句即可。

## §10 参考公式

### 10.1 导演公式 → 规则映射

| 公式槽位 | 规则步骤 |
|---|---|
| Subject | 第 4 步 人物分点 |
| Action | motion_desc |
| Scene | 第 2 步 环境 |
| Camera | 第 3 步 镜头参数 |
| Lighting/Style | 第 6 步 光影 |
| Audio | 规则 12.5 音效轨 |
| Constraints | 第 7 步 约束收尾 |

### 10.2 压缩优先级

删：重复风格形容词 → 画质泛词 → 参考图已有背景 → 次要运镜 → 次要动作；
保留：主体/动作/相机/光/约束。

### 10.3 事件三分桶

- **already_happened**：上一镜 lf 承接，不重放
- **this_clip_only**：本镜执行的动作
- **reserved_for_later**：保留给打斗反转/大招
