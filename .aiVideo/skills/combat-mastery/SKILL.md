## §1 四类打斗节奏镜

### 1. 旋转攻击镜（范围技/武器回旋）

- 镜头节奏：360° 环绕攻击者，环绕与挥击同速，每绕一圈切换招式轨迹展示角度
- 适用：主角大招、范围技能、武器回旋斩
- 模板：`镜头以攻击者为中心 360° 环绕，环绕与挥刀动作同速，刀锋每转一圈带出弧状刀光，第二圈切低角度拍招式轨迹，第三圈切远景展示范围冲击`

### 2. 躲避晃动镜（受击闪避）

- 镜头节奏：受击瞬间镜头剧烈晃动+画面颠簸，闪避完成后 0.3 秒短暂稳定
- 适用：躲暗器/箭矢、陷阱触发、被追杀
- 模板：`第一人称视角，暗器迎面飞来，镜头随侧身闪避剧烈晃动、画面颠簸，闪避落地后镜头稳定 0.3 秒`

### 3. 时间凝滞镜（绝杀/危机压迫）

- 镜头节奏：高速运动中画面突然定格 2 秒（所有元素静止、细节清晰），随后缓慢恢复
- 适用：绝杀瞬间、关键打击
- 必写时长分配：前 X 秒常速 → X-X+2 秒定格 → 剩余恢复，禁止笼统"全程慢动作"
- 模板：`前 1 秒：挥刀劈下；1-3 秒：画面定格，刀锋悬停空中，碎屑悬浮不落；3-5 秒：刀锋继续劈落，画面恢复动态`

### 4. 打斗穿梭镜（混战/高速对决）

- 镜头节奏：镜头在交战双方间快速穿梭，单次停留 ≤0.8 秒，穿插 0.2 秒慢动作特写
- 适用：激烈格斗、多人混战、高速对决
- 模板：`镜头在双方之间快速穿梭，左方拳击瞬间停 0.5 秒给拳锋特写，右方回旋踢插 0.2 秒慢动作，随后继续高速穿梭`

## §2 招式词库与完整模板

### 核心原则

1. **招式必须具体**：禁止只写"两人激烈交手"，必须写招式名+打击部位+反馈效果
2. **每镜一个打击反馈**：2-3 秒打斗镜只承载 1 个核心动作 + 1 个可感知反馈（冲击波/火星四溅/碎屑飞溅/衣袂翻飞/动态模糊/速度线/气浪）
3. **节奏变化**：快→定格→再动的张力，禁止全程匀速挥打

### 动作细节关键词

- **拳法**：直拳、摆拳、勾拳、连环拳、反手拳、虚晃拳
- **掌法**：推掌、劈掌、拍掌、横掌、双掌推出、反掌
- **腿法**：高扫腿、低扫腿、后踢、回旋踢、腾空踢、蹬踢、飞踢、旋风腿
- **通用强化词**：动态模糊、速度线、冲击波、碎屑飞溅、肌肉紧绷、衣袂翻飞、气流扰动、火星四溅、火花四溅、气浪、飞沙走石

### 完整招式模板（带受力/特效）

**拳脚近战**：
```
【蓄力出拳】右臂后拉蓄力，肩部肌肉绷紧，身体重心下沉，半秒后全力挥出直拳，拳头落点处空气震动，对方头部被打得偏向一侧，汗珠飞溅
【飞踢凌空】身体腾空跃起，右腿屈膝上抬后猛然伸直，脚掌精准命中对方下颌，冲击力使对方身体后仰
【膝顶腹击】膝盖弯曲蓄力后猛然顶向对方腹部，对方身体瞬间蜷缩后退，脚下地面震起细碎尘土
【回旋踢】身体以腰为轴快速旋转，左腿横向扫击对手躯干，带出轻微气流残影
```

**冷兵器**：
```
【兵器相击】双方刀剑在空中碰撞，火星四溅，冲击波沿兵器传导至手臂，指节因握力而发白，双方脚下地面出现裂纹
【青蓝剑气斩击】人物挥剑斩击，剑刃拉出修长青蓝色剑气流光，剑端灵气星点飘散，斩击轨迹清晰利落
【刀芒瞬闪暴击】人物挥刀劈砍，刀身迸发刺眼亮白刀芒，刀光瞬间炸开，对手被击中的位置出现凹陷
【腾空下劈】角色高高跃起，双手握剑举过头顶，急速下落劈向对手肩颈，地面被劈出一道浅沟
```

## §3 四段式节奏框架（整段打斗）

### 1. 对峙阶段（开场，0-10s）

- 近景/特写快速交代双方状态，运镜偏**固定**，突出"一触即发"
- 模板（1-2s/镜）：主角眼神近景固定 → 反派武器特写 → 全景战场环境建立

### 2. 攻防阶段（主体，10-85s）

- **1-2 秒短分镜为主**，大量快速推/拉/跟拍
- 中间穿插 **3-4 秒中长镜头**展示关键招式
- 蒙太奇组合：全景→中景跟拍→脚步特写→脸部特写（保持动作连贯）

### 3. 反转阶段（大招/施法/蓄力，85-155s）

- **超长镜头（10s+）+ 慢镜头 + 环绕运镜** 展示施法/蓄力/大招过程
- **规则 7 短镜铁律的唯一例外**：仅限特效/蓄力过程（3-5s 起）
- 运镜服务情绪：反派得势=高速后拉+仰拍；主角反击=环绕+推镜

### 4. 收尾阶段（155-185s）

- 大远景/空镜拉长时间，突出战后平静
- 情绪升华：空镜叠化（极光/月夜/山水）转场，5-10s

### 节奏控制三技巧

1. **快慢结合**（紧-松-紧）：高速打斗短镜快切，关键施法/蓄力长镜慢放
2. **景别交替**：近景特写+全景大远景交替，禁止连续多镜同景别堆打斗
3. **运镜服务情绪**：被动=高速后拉+仰拍，反击=环绕+推镜

## §4 武器运镜（剑/琴/刀/枪）

### 剑类

- **风格**：CG 国风写实质感，物理级布料动态，冰金色兵器轨迹光效
- **运镜流程**：
  - 0-3 秒：环绕急推，从龙头推至女主眼部特写
  - 0-13 秒：跟拍横移，冰剑出鞘斩出冰金轨迹
  - 1-25 秒：螺旋升空，踏空跃起人龙同步挥剑
  - 2-45 秒：360° 环绕运镜
  - 5-85 秒：急拉定格特写，收剑垂眸
- **关键词**：`环绕急推|跟拍横移|螺旋升空|360° 环绕|急拉定格|冰金轨迹|人龙合一`

### 琴类

- **风格**：水墨粒子特效，金色光粒，白衣长发
- **分镜**：手指拨弦（特写）→ 抚琴（中景）→ 光剑飞出（全景）→ 抬眼远望（特写）
- **关键词**：`水墨粒子|琴弦震动|金色光粒|光剑凝聚|长发飘动|云雾仙山`

### 刀类

- **风格**：暗黑武侠，金属冷光，黑红配色
- **分镜**：女子冲入劈砍（低角度全景）→ 对刀火花（中景）→ 手腕翻转长刀旋转（特写）→ 收刀敌人倒地（近景）
- **关键词**：`暗黑武侠|金属冷光|红色残影|火花四溅|手腕翻转|长刀旋转|古战场`

### 枪类

- **风格**：国风玄幻，粉色与紫色光效
- **分镜**：女子持枪冲锋 → 刺出枪击中怪物 → 旋转枪展开光盾 → 燃烧荒原上拄枪远望
- **关键词**：`国风玄幻|粉色光效|紫色光效|长枪冲锋|光盾防御|荒原燃烧|长发飞扬`

### 武器光效关键词

## §5 万人战争分层渲染

### 四层画面分层结构（由近到远）

1. **英雄层（前景）**｜1-3 人：主角、关键将领，细节完整
2. **近景动作层**｜8-20 人：冲锋、厮杀、格斗，保留盔甲武器细节
3. **中景队列层**：大量重复阵列士兵，允许复用资产变体
4. **远景密度层**：旗海、矛林、烟尘、人海轮廓

### 场景 DNA（世界观恒定参数）

同一场战役全部镜头共用：地形建筑、光照、环境氛围、尺度锚点。

### 战场资产预制

- 盾牌：6 套基础款式，同款不同磨损
- 头盔：5 套，敌我阵营轮廓必须有明显区分
- 长矛：3 种长度（适配近/中/远景）
- 旗帜：4 组，阵营颜色、纹样固定

### 合成顺序（流水线生成顺序）

**先大后小，先光后人，先空间后气氛**：
1. 锁定地平线、太阳光照方向
2. 生成地形、城墙、战船等大型地物块
3. 铺中景军团队列、旗海阵列
4. 叠加前景英雄、近景厮杀士兵
5. 最后叠加扬尘、烟尘、雾气遮挡层

### 一眼廉价的 5 个 AI 翻车信号

1. 近景、远景士兵尺寸不符合透视
2. 同一阵营旗帜纹样颜色每镜完全不一样
3. 毫无缘由到处爆炸、漫天火海
4. 建筑、战车、人物之间没有可信尺度对比
5. 误以为宏大 = 把画面全部塞满；**留白与层次才是史诗感**

### 分镜字段要求

- 大战场镜头标 `scene_layer`：hero_layer / near_action / mid_queue / far_density
- 大战场镜头绑定 `battle_asset_group`（复用预制盾牌/头盔/旗帜）
- 同一战役所有镜头继承 `world_dna`（光照/地形/烟尘色调固定）
- 提示词分层书写：先环境光照 DNA → 再四层画面 → 最后运镜

## 适配要点

- **一镜一动作铁律**：2-3 秒打斗镜只写 1 个招式，时间凝滞/慢动作属节奏修饰
- **时长分配必写**：用时间凝滞/慢动作必须写"前 X 秒…；X-Y 秒…；剩余…"三段
- **禁用形容词**：禁止"矫健/迅猛/凌厉"等抽象词和"如闪电"等比喻
- **合规替换**：血→红、刺→掠、杀→击、死→倒；血迹只许少量暗红洇痕
- **竖屏适配**：环绕/穿梭多用纵向运动，主体保持画面中央
