# 首尾帧衔接速查（first-last-frame-guide）

> 精简自 seedance-2.0 references/first-last-frame-guide.md，适配 aiVideo 分镜。

## 核心原则
- **首帧定义起点，尾帧定义目标态**。prompt 只描述过渡逻辑/相机/光照/声音/保持不变项。
- **贯穿元素（carrier）**：选 1 个不变元素（刀尖/光源/机位/服装件）跨首尾帧位置恒定，防主体变形。
- **动作只发生一次**：ff 定格起点的前一瞬，lf 是结果，不是第二遍动作。

## 过渡逻辑模板
```
ff 定格：[前一刻状态，如刺客潜伏水下、匕首未出水]
lf 结果：[结束态，如刺客没入水中、刀尖仅余一截]
过渡：只生成两帧之间的连续动作
Motion：一条物理动作路径
Camera：一个受控机位或锁定
Lighting：光源与连续性
Sound：环境/对白/音效/静音
Constraints：无新文字、无水印、无身份变化、无物体重新设计
```

## 参考角色
- 首帧：`@Image1 为首帧`
- 尾帧：`@Image2 为尾帧`
- 身份锁定：`保持同一主体、服装、形状和场景逻辑`
- 仅过渡：`只生成两帧之间的连续动作`

## 检查
- 首尾帧姿态显著不同（防构图撞车）
- 贯穿元素存在且位置恒定
- lf 可被下一镜 ff 直接承接
