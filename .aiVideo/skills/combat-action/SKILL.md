# AI漫剧打斗动作提示词库

> 适配 aiVideo 古风真人竖屏打斗分镜。
> 核心：打斗镜头不写抽象"交手/打斗"，必须有 **具体招式** + **打击反馈** + **节奏变化**。

## 核心原则（最高优先级）

1. **招式必须具体**：打斗 prompt 禁止只写"两人激烈交手"——必须写出具体招式名（拳/掌/腿法）+ 打击部位 + 反馈效果。
2. **每镜一个打击反馈**：2-3 秒打斗镜只承载 1 个核心动作，且该动作必须带 1 个可感知的反馈元素（冲击波/火星四溅/碎屑飞溅/衣袂翻飞/肌肉紧绷/动态模糊/速度线/气浪/飞沙），禁止"挥空拳"式的无反馈打斗。
3. **节奏变化**：打斗的"劲"来自节奏差——快→定格→再动的张力（时间凝滞）、受击→闪避→稳定的节拍（躲避晃动）。禁止全程匀速挥打。

## 一、四类打斗节奏镜（直接套用）

### 1. 旋转攻击镜（范围技/武器回旋）

- 镜头节奏：以攻击者为轴心 360° 环绕，环绕速度与挥击节奏同步（挥刀一圈=镜头绕行一圈），每绕一圈切换一次招式轨迹展示角度。
- 适用：主角大招、范围技能、武器回旋斩。
- prompt 模板：
  ```
  镜头以攻击者为中心 360° 环绕，环绕与挥刀动作同速，刀锋每转一圈带出弧状刀光，第二圈切低角度拍招式轨迹，第三圈切远景展示范围冲击
  ```

### 2. 躲避晃动镜（受击闪避）

- 镜头节奏：第一人称躲避视角，受击瞬间镜头剧烈晃动 + 画面颠簸，闪避完成后 0.3 秒短暂稳定再继续。
- 适用：躲暗器/箭矢、陷阱触发、被追杀。
- prompt 模板：
  ```
  第一人称视角，暗器迎面飞来，镜头随侧身闪避剧烈晃动、画面颠簸，闪避落地后镜头稳定 0.3 秒
  ```

### 3. 时间凝滞镜（绝杀/危机压迫）

- 镜头节奏：高速运动中画面突然定格 2 秒（所有元素静止、细节清晰），随后缓慢恢复动态。
- 适用：绝杀瞬间、关键打击、危机压迫。
- 必写时长分配：前X秒常速 → X-X+2秒定格 → 剩余恢复，禁止笼统"全程慢动作"。
- prompt 模板：
  ```
  前1秒：挥刀劈下；1-3秒：画面定格，刀锋悬停空中，碎屑悬浮不落，双方表情清晰；3-5秒：刀锋继续劈落，画面恢复动态
  ```

### 4. 打斗穿梭镜（混战/高速对决）

- 镜头节奏：镜头在交战双方间快速穿梭，单次停留 ≤0.8 秒，穿插 0.2 秒慢动作特写。
- 适用：激烈格斗、多人混战、高速对决。
- prompt 模板：
  ```
  镜头在双方之间快速穿梭，左方拳击瞬间停 0.5 秒给拳锋特写，右方回旋踢插 0.2 秒慢动作，随后继续高速穿梭
  ```

## 二、分镜级动作模板（景别/机位/节奏）

### 1. 压迫式逼近

- 景别：大全景｜机位：低机位仰拍｜运镜：缓慢前推
- 动作：对手步步逼近，剑尖贴地拖行，地面尘土被剑尖压起
- 节奏：沉重压抑 → 爆发｜情绪：压迫窒息
- 光影：逆光剪影，乌云翻涌

### 2. 剑锋相撞

- 景别：特写｜机位：平拍｜运镜：急速前推
- 动作：双剑刃口撞击，火星四溅，虎口青筋暴起
- 节奏：撞击瞬间凝固｜情绪：力量对等、寸步不让
- 光影：强光爆闪，金属冷光反射在双方脸上

### 3. 凌空劈斩

- 景别：全景｜机位：低角度仰拍｜运镜：快速上移跟拍
- 动作：角色跃起双手握剑举过头顶，脊背弓起
- 节奏：腾空蓄力 → 急速下落｜情绪：一决生死的决绝
- 光影：逆光勾成剪影，阳光从背后炸开

## 适配 aiVideo 的注意点

- **一镜一动作铁律**：2-3 秒打斗镜只写 1 个招式，连贯招式用短镜快切 + 0.2s 硬切拼接；时间凝滞/慢动作属于节奏修饰，可叠加在单个动作上，不算堆招式。
- **时长分配必写**：用时间凝滞/慢动作时必须写"前X秒…；X-Y秒…；剩余…"三段时间分配，禁止笼统"全程慢动作"。
- **禁用形容词**：角色动作禁止"矫健/迅猛/凌厉"等形容词和"如闪电"等比喻，一律换具体动作（招式名+打击部位+方向）。
- **合规替换**：血→红、刺→掠、杀→击、死→倒；血迹只许少量暗红洇痕，禁止血迹特写。
- **竖屏适配**：环绕/穿梭多用纵向运动（上下移动）替代横向，主体保持在画面中央。
