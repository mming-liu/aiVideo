# 克制感情绪戏（微表情时间链）

> 适配 aiVideo 古风真人竖屏分镜。
> 核心：**情绪越克制越动人**。告别/隐忍/失落这类情绪，禁止写「大哭」「痛哭」「猛烈摇头」等外放大动作——情绪要压在细节里，用**微表情时间链**逐拍递进，让观众从「嘴角/眼神/泪光」的细微变化里读出内心。

## 核心原则（最高优先级）

1. **克制基调优先**：哭戏不写「大哭」，写「无声哭/隐忍/眼含热泪但忍住不落」；失落不写「瘫坐捶地」，写「垂眼失神/发呆」。情绪浓度全压在微表情，不是动作幅度。
2. **微表情时间链（核心）**：一个克制情绪镜头 = 2-3 拍微表情，每拍一个具体面部细节，按时间先后逐拍递进。禁止只写一个情绪词、一个表情定住。
   - 告别链示例：低头隐忍 → 眼含热泪 → 微笑释怀
   - 失落链示例：垂眼失神 → 眼尾泛红 → 低头苦笑
3. **禁止抽象情绪词**：照旧落到「情绪可视化」，且克制情绪必须落到面部细节（眼眶泛红/嘴角紧闭/睫毛颤动/目光低垂），不是肢体大动作。
4. **光影绑定情绪**：克制情绪配合低饱和暖/冷光、慢镜头/特写，给微表情放大空间；氛围光来自画面真实光源（烛火/月光/窗光）。

## 克制情绪戏模板（直接套用）

```
[景别：近景/特写] [人物身份+神态]，[第1拍微表情：低头/垂眼/抿唇]，
眼眶泛红/睫毛颤动，[第2拍微表情：抬眼/泪光/嘴角变化]，
[第3拍微表情：释怀/苦笑/别过脸]，[慢镜头/固定特写]，[低饱和暖光/冷光+真实光源]
```

### 告别（释怀）示例

```
古风女子近景特写，欧式卷发披散，低下头压住情绪（嘴角紧闭，睫毛轻颤），
慢慢抬眼，眼中已蓄满泪光（眼泪将落未落），
随后浮起一个极浅的释怀微笑，转头望向远方。
慢镜头，暖金色余晖从画左斜照（逆光轮廓），画面安静克制。
```

### 失落示例

```
古风长发女子中近景，垂着眼失神（目光低垂无聚焦），
眼尾渐渐泛红（强忍住泪意），
低头苦笑一下，别过脸望向画右。
柔和冷调月光从画上方洒落，慢镜头，安静无声。
```

### 内心紧张（不哭，憋着的紧张）示例

```
拟人化角色面部特写，呼吸微微加快（胸口起伏），眼神凝住警惕，
嘴角轻轻抿紧又松开，瞳孔微缩，
抬眼看向画左威胁来源。硬光顶灯制造压迫感，静止镜头。
```

## 落地要点

- 现有情绪可视化（_EMOTION_ACTION_MAP）已覆盖单情绪→单动作映射；本库补齐「**多拍递进**」这一层——克制情绪镜头至少 2 拍微表情，按时间先后写全。
- 克制情绪词（隐忍/释然/失落/苦笑/哽咽/噙泪/别过脸）触发时，validation 检查是否同时满足：克制基调（无大哭/痛哭/猛摇头）+ 微表情链（≥2 个面部细节）+ 无抽象情绪词。
- 禁止组合：克制情绪 + 大哭/暴怒大动作；哭泣镜头禁止「悲痛欲绝」类形容词堆砌。
