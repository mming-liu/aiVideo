# 万人战争分层渲染（大战场镜头）

## 核心思想

**不要让AI一次性生成上万士兵**。宏大战场的氛围感来自分层、透视、密度，而不是塞满画面。先做资产模块，再分层拼接画面。

## 一、四层画面分层结构（由近到远）

> 规则：距离越远，单个人物细节越少，重点保留轮廓、阵列密度，不需要精细五官。

1. **英雄层（前景）｜1-3人**：主角、关键将领，承担叙事，细节完整，铠甲面部精细。
2. **近景动作层｜8-20人**：冲锋、厮杀、格斗，负责冲击力，动作丰富，保留盔甲武器细节。
3. **中景队列层**：大量重复阵列士兵，体现军队秩序阵型；允许复用资产变体，不能每个人完全一样。
4. **远景密度层**：旗海、矛林、烟尘、人海轮廓；不需要分辨单个人脸，只靠色块轮廓体现千军万马。

## 二、场景 DNA（世界观恒定参数，强制不变）

同一场战役全部镜头共用这套参数，避免画面风格光影乱跳：
1. **地形建筑**：城墙、滩涂、营寨结构固定
2. **光照**：太阳方位、阴影投射方向固定
3. **环境氛围**：烟尘颜色、雾气浓度；禁止无逻辑漫天火海爆炸
4. **尺度锚点**：城门、战车、战马，约束士兵大小，防止透视崩坏

> 世界观不是简单风格词，是一组不可修改的物理参数。

## 三、先预制战场资产模块

不要每镜临时随机生成武器盔甲，提前产出有限变体资产复用：
- 盾牌：6套基础款式，同款不同磨损破损
- 头盔：5套，敌我阵营轮廓必须有明显区分
- 长矛：3种长度，分别适配近景/中景/远景
- 旗帜：4组，阵营颜色、纹样固定
- 战车、战船：严格透视缩放，远小近大

> 原则：复制可以被看见，但变化要有规则。

## 四、宏大场景合成顺序（流水线生成顺序）

**先大后小，先光后人，先空间后气氛**：
1. 锁定地平线、太阳光照方向
2. 生成地形、城墙、战船等大型地物块
3. 铺中景军团队列、旗海阵列
4. 叠加前景英雄、近景厮杀士兵
5. 最后叠加扬尘、烟尘、雾气遮挡层

## 五、一眼廉价的 5 个 AI 翻车信号（自检表）

1. 近景、远景士兵尺寸不符合透视，远景人物反而很大
2. 同一阵营旗帜纹样颜色每镜完全不一样
3. 毫无缘由到处爆炸、漫天火海
4. 建筑、战车、人物之间没有可信尺度对比
5. 误以为宏大 = 把画面全部塞满；**留白与层次才是史诗感**

## 分镜字段要求

- 大战场镜头标 `scene_layer`：hero_layer（英雄层）/near_action（近景动作层）/mid_queue（中景队列层）/far_density（远景密度层）
- 大战场镜头绑定 `battle_asset_group`（复用预制盾牌/头盔/旗帜资产，禁止AI自由随机设计军备）
- 同一战役所有镜头继承 `world_dna`（光照方向/地形/烟尘色调固定）
- 提示词分层书写：先环境光照DNA → 再四层画面 → 最后运镜；不把上万士兵全堆在一句
