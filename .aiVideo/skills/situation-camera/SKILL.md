# 情景剧 18 种运镜速查表

> 核心原则：**运镜服务于剧情与人物情绪**，告别"乱推乱摇"的无效镜头。
> 可直接套用于短剧、剧情号、AI 漫剧。适配 aiVideo 古风真人竖屏分镜。

## 运镜速查表（18 种）

| 运镜类型 | 核心用法 | 情绪效果 | 适用场景 |
|----------|----------|----------|----------|
| 推镜（情绪聚焦） | 缓慢推近人物面部特写，放大眼神、微表情变化 | 强化情绪、聚焦人物内心 | 情绪爆发、秘密揭露、告白场景 |
| 拉镜（氛围烘托） | 快速拉远画面，从人物特写拉到全景，展现环境与人物的关系 | 凸显孤独、无助、宏大感 | 离别、失去、史诗级场景 |
| 跟镜（代入感） | 平稳跟随人物移动，保持固定距离，不偏离主体 | 增强观众代入感、跟随剧情节奏 | 追逐、跟踪、日常行动场景 |
| 摇镜（空间展示） | 从左到右/从上到下缓慢摇摄，展现完整空间环境 | 交代场景、营造氛围 | 房间介绍、环境展示、悬疑场景 |
| 移镜（层次感） | 横向移动镜头，利用前景遮挡，展现画面层次感 | 增强空间深度、丰富画面 | 对话、互动、多人场景 |
| 甩镜（节奏加速） | 快速甩动镜头，从一个人物/场景切换到另一个 | 营造紧张、急促、反转感 | 打斗、追逐、剧情反转场景 |
| 环绕镜（名场面） | 围绕人物360°匀速环拍，展现人物全貌与空间关系 | 打造高光时刻、强化人物气场 | 主角出场、高光时刻、仪式感场景 |
| 低角度仰拍（压迫感） | 镜头从下往上仰拍，强化人物高大形象 | 凸显权威、压迫感、英雄主义 | 反派出场、主角高光、权力场景 |
| 高角度俯拍（无助感） | 镜头从上往下俯拍，人物显得渺小 | 凸显无助、孤独、被监视感 | 悬疑、惊悚、弱势角色场景 |
| 过肩镜（对话感） | 镜头从一个人物肩膀后方拍摄，聚焦另一个人物 | 增强对话真实感、拉近观众距离 | 双人对话、对峙、秘密交流场景 |
| 正反打镜（对话节奏） | 交替拍摄对话双方，切换景别与角度 | 加快对话节奏、强化情绪冲突 | 多人对话、争吵、谈判场景 |
| 手持镜（真实感） | 模拟手持拍摄的轻微晃动，不稳定但自然 | 增强纪实感、真实感、紧张感 | 纪实类、悬疑、紧急场景 |
| 变焦镜（视觉冲击） | 突然放大/缩小画面，聚焦关键细节 | 强化震惊、顿悟、抓眼球效果 | 反转、发现线索、高光时刻 |
| 空镜转场（氛围过渡） | 拍摄无人物的空镜，自然过渡到下一场景 | 舒缓节奏、营造氛围、转场自然 | 时间跳转、情绪过渡、场景切换 |
| 慢动作镜（情绪放大） | 放慢动作，捕捉细节与情绪 | 强化感动、悲伤、震撼感 | 告白、离别、高光时刻 |
| 快动作镜（节奏加速） | 加快动作，压缩时间 | 营造紧张、急促、喜剧感 | 追逐、搞笑、紧急场景 |
| 长镜头（叙事连贯） | 连续拍摄长镜头，不剪辑，完整展现事件过程 | 增强叙事连贯性、真实感 | 复杂动作、长对话、纪实场景 |
| 分割画面镜（平行叙事） | 同时展示两个或多个场景，分割画面 | 展现平行事件、对比、紧张感 | 双线叙事、对比、悬疑场景 |

## 核心使用技巧

1. **运镜服务剧情**：根据剧情节奏与人物情绪选择运镜方式，情绪爆发时用推镜、慢动作，紧张场景用甩镜、手持镜。
2. **景别与运镜结合**：特写用推镜放大情绪，全景用拉镜展现环境，中景用跟镜、移镜增强互动。
3. **避免过度运镜**：运镜过多会导致观众注意力分散，关键场景用运镜强化，普通场景用固定镜头或简单运镜。
4. **参数补充**：在提示词后可补充`4K高清、电影感、动态模糊、浅景深`等画质词，进一步提升效果。

## 适配 aiVideo 的注意点

- **每个 AI 分镜只承载 1 种主导运镜**：同一镜头禁止堆叠多段运镜（如"推近后再环绕"），一镜一运镜，变化交给相邻镜头的 clip_transition。
- **打斗/追杀**：仍遵守短镜快切铁律（2-3 秒/镜 + 0.2s 硬切），甩镜、手持镜、快动作镜优先，禁止用环绕/慢动作拖慢节奏。
- **竖屏 9:16**：环绕、移镜、甩镜多用纵向运动（上下移动）替代横向，画面主体保持在中央区域。
- **过肩 / 正反打**：跨相邻镜头实现——镜头 A 从 A 肩后拍 B，镜头 B 反向从 B 肩后拍 A，即成"过肩→反打"对话节奏。
- **空镜转场**：空镜遵守空镜约束（画面无人物），作场景切换/时间跳跃镜头，clip_transition 用淡入淡出。
- **慢动作 / 快动作**：在 prompt 中显式写"慢动作"或"快进"及时长占比（如"前 3 秒慢动作；剩余时长常速"），禁止笼统写"全程慢动作"。
- **长镜头**：仅限超长镜头（>8 秒）时使用，动作连续推进需按时间段描述；打斗禁止长镜头慢放。
- **固定机位是基础**：普通对话/静态镜头默认固定，不因运镜失去焦点（与 AI 短剧总规则 21 一致）。
