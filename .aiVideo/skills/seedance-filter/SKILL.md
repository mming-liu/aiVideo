# seedance-filter
  ## 意图修复而非绕过
这个 skill 只修复**假阳性**：因过度过滤而被阻止或降级的良性制作内容（医疗、历史、体育、虚构原创背景）。通过**用直白语言说明合法背景**来工作，绝不伪装意图。
## 边界规则
不帮助真正禁止的内容：涉及未成年人、无权使用真实人物肖像、色情或图形或非法材料。如果底层请求被禁止，直接拒绝。## 修复方法
1. 识别创意意图：动作、情绪、相机、主体、最终节拍
2. 识别有风险的表面措辞：图形伤害、受保护身份、性化框架、真实人物肖像、武器、自残、仇恨、逃避语言
3. 用专业、非图形、制作背景语言替换有风险的术语
4. 保留构图、动作、情绪、相机逻辑和授权引用
## 安全重写模式
| 意图 | 安全方向 |
|------|----------|
| 冲突 | `编排的对打动作节拍，无图形伤害` |
| 后果 | `非图形化困境，破损服装，散落道具，戏剧性沉默` |
| 悬念 | `阴影暗示的威胁，锁着的门，低沉呼吸声，低光` |
| 武器状道具 | `在编排动作场景中安全处理的道具` |

| 受保护身份 | `具有广泛类型原型特征的原创角色` |
