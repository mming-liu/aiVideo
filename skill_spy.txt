# 国风动漫短视频生成 · 提示词工程参考库

> 与 `01_script_gen.py` 的 PROMPT_TEMPLATE、`style_prefix.py` 配套使用。
> 三处"固定前缀"必须保持一致，改动任一处须同步。

## 1. 画面统一前缀（每条 prompt 强制携带，三处一致）
国风动漫影视剧，9:16竖屏，电影柔光，暗调低饱和，烛火局部光影，浅景深缓慢向前推镜，精美2D动画风格，无真人写实，高清1080P

## 2. 负面提示词（固定）
真人写实、写实风格、畸形五官、明亮强光、现代服装、3D渲染、塑料质感、明亮阳光

## 3. 高频镜头素材词库
1. 钩子镜头：月下宫殿飞檐剪影，主角立檐角衣袂翻飞，远山云海翻涌
2. 密谈镜头：竹林深处灯火隐现，两人对峙剑拔弩张，竹叶簌簌落下
3. 反转镜头：卷轴缓缓展开，封印符咒一颗颗碎裂，灵光冲天而起
4. 战斗镜头：山巅云海之上，双剑交击迸发气浪，衣发猎猎作响
5. 回忆镜头：樱花瓣瓣飘零庭院，师父背影渐行渐远，手心中一枚玉佩
6. 结尾悬念：孤舟独行于星辰大海，天边一道流星划过，主角侧脸微光勾勒

## 4. 文本转镜头规则
1. 心理描写全部转为肢体、眼神、环境光影、特效化的情绪符号（如灵气、花瓣、风），禁止内心独白。
2. 单条短视频 N 个镜头（N 由 LLM 根据章节长度和情节复杂度决定，默认 4-12），每镜 4-6 秒，总时长 = N×5 秒，适配抖音竖屏 9:16。
3. 旁白古风短句，总字数约 N×40 字，低沉成熟男声朗读。
4. 前 1/3 镜头取原文开头、中间 1/3 取中段、最后 1/3 必须取结尾强事件，禁止全部取自前半段。
5. 跨镜头人物外貌须一致（发型、瞳色、服装、标志性配饰）。
6. 相邻镜头景别不得重复，所有镜头至少使用 3 种不同景别。

## 5. 合规底线（二次元动漫，阈值宽于真人写实）
- 用"赤足/赤膊"替代"光腚/裸"。
- 其他低龄/暴力词在动漫语境下通常可保留；若平台审核严，参考 `style_prefix.py` 替换表。
- 禁止过度裸露描写。

## 6. FFmpeg 调色固定参数
对比度1.15，饱和度0.85，加重暗角，轻微胶片颗粒，冷调偏蓝动漫色调。
