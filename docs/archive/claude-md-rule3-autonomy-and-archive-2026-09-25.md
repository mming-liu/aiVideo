# CLAUDE.md 准则 3 调整：大事交用户、小调整自行决定 + 强制留档（2026-09-25）

## 改了什么

`CLAUDE.md` → 「工作准则」第 3 条，由原来的单句

> **3. 不擅自改已确认的决策。** 用户或计划文档已确认的方向、数值、预算属用户决策：
> 发现问题时提出＋给证据，由用户决定，不自行改动。

改写为**两档判定 + 留档要求**：

| 档 | 范围 | 处理方式 |
|---|---|---|
| **重大事项** | 已确认的方向/数值/预算（修复轮数上限、联动组容量、某功能是否休眠）；一切**改变对外行为、成本或生产结论**的取舍（判据口径、授权面、门禁语义、发布/回滚策略） | 提出 + 给证据，**由用户决定**，不自行改动 |
| **小调整** | 命名与文案、日志/报错措辞、注释与文档、测试夹具与断言、明显笔误与死代码、不改行为的等价重构，以及**把已确认的修法对齐到同族位置** | **自行决定并直接做完**，不必逐条请示 |
| 判定口径 | **拿不准就按重大处理**；第 4 条**花钱**动作与第 5 条**不可逆/对外**动作不受放宽 | —— |

并新增**留档（强制）**段落：任何调整（**含**自行决定的小调整）都要在 `docs/` 下新建
`<主题>-<YYYY-MM-DD>.md`，写清**改了什么 / 为什么（根因与证据）/ 影响面 / 实跑测试数字与
回退方式**；没有留档的改动不算完成。

## 为什么

用户 2026-09-25 指出：此前每条调整（含夹具修正、文案、同族对齐这类小改动）都要单独请示，
交互成本高于收益；但「自行决定」若无留档，事后无法回溯是谁、为什么、依据什么数字改的。
两条要求配套：**放权 + 留痕**。

## 影响面

- 只改 `CLAUDE.md` 的协作文档，**不影响任何代码路径、产物、成本**。
- 行为变化仅限协作方式：小调整不再逐条请示，但必须以 `docs/` 文档 + 汇报里的实跑数字留痕。
- 仍**必须**先请示的：动判据/授权面/门禁语义、改已确认数值、接生产（大纲/提示词/
  BEST-GUARD/质量门）、真实模型调用与整章运行、花钱与不可逆动作。

## 验证

- 文档类改动，无测试可跑；`CLAUDE.md` 已按 UTF-8 保存（项目编码规范）。
- 回退方式：把第 3 条还原为原文单句、删除新增的留档段落即可（无代码依赖）。
