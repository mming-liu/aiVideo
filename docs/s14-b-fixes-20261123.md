## 2. [P1] 声音修订可能把另一角色的原话安到旧说话人

`step01_script_gen/lightweight_voice_repair.py`：

- 候选来源改为**本声音自身优先**：正文逐字可定位时只从它所在的引语取候选，不再用
  绑定证据扩展（证据可能是另一角色的原话，而应用器保留旧 `speaker`）。
- 正文定位不到时才用绑定证据；对白证据必须落在**归属同一说话人**的引语里
  （`_quote_owner` 取开引号前的归属叙述核对），归属不符或无法核对 ⇒ 不给候选（fail-closed）。
- 候选还要求与锚点**同一引语 span**（替代旧的「同引号内外」布尔判断），旁白不得借用
  某人的引语。
- 新增 3 条测试：跨说话人证据不进菜单且 `apply` 拒收、非逐字声音的异归属证据不给候选、
  既有同引语候选用例保持。

## 3. [P2] 候选压缩删掉可行短句，误判「不可修」

同一模块：

- `_options` 返回「压缩排名菜单 + 完整合法候选集」；`_best_case` 的不可修预判改用
  **完整候选集**（`full=True`），不再仅凭压缩后的菜单下结论。
