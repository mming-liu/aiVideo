# Token Plan FAQ

> Agnes AI 访问计划、API 密钥、RPM 限制和订阅配额说明

**生效日期：** 2026-06-22\
**视频 RPM 更新日期：** 2026-06-28\
**版本：** 当前公开参考版本

本文档说明 Agnes AI 当前不同访问类型的 **文本模型、图片模型、视频模型 RPM 限制**，以及 **Token Plan 订阅配额**。

<Note>
  以下数值为当前公开参考值，Agnes AI 可能会根据基础设施容量、服务稳定性、模型可用性、滥用防范或产品策略进行调整。
</Note>

***

## 1. 访问类型

Agnes AI 当前支持三种访问类型：

| 访问类型          | 说明                            |
| ------------- | ----------------------------- |
| 免费 / 默认用户     | 未订阅 Token Plan，且未完成企业认证的用户    |
| 企业认证用户        | 已完成企业认证，拥有更高基准访问限制            |
| Token Plan 用户 | 已订阅 Token Plan，拥有更高 RPM 和订阅配额 |

同一用户可以同时拥有多种访问类型。

例如，用户可以同时拥有：

* 免费 / 默认密钥
* 企业认证密钥
* Token Plan 密钥

不同类型的密钥使用不同的限制池。

***

## 2. Token Plan 配额总量

除 RPM 限制外，Token Plan 用户还受订阅配额限制。\
**RPM 限制** 和 **订阅配额** 会同时生效。

| Plan    | `agnes-2.0-flash`            | `agnes-image-2.0 / 2.1-flash` | `agnes-video-v2.0` |
| ------- | ---------------------------- | ----------------------------- | ------------------ |
| Starter | 每 5 小时 1,500 次；每周 15,000 次   | 每天 4,000 张                    | 每天 500 秒           |
| Plus    | 每 5 小时 7,500 次；每周 75,000 次   | 每天 4,000 张                    | 每天 500 秒           |
| Pro     | 每 5 小时 30,000 次；每周 300,000 次 | 每天 4,000 张                    | 每天 500 秒           |

### 说明

* 文本模型配额按 **请求次数** 计数。
* 图片模型配额按 **生成图片张数** 计数。
* 视频模型配额按 **生成视频时长（秒）** 计数。
* Token Plan 用户既受 **RPM 限制**，也受 **订阅配额限制**。

## 3. 文本模型 RPM 限制

| 模型类型 | 用户类型         | 分辨率 / 规格 | 允许发起 RPM | 实际 RPM |
| ---- | ------------ | -------- | -------: | -----: |
| 文本模型 | `default`    | -        |       30 |     20 |
| 文本模型 | `enterprise` | -        |       60 |     40 |
| 文本模型 | `TokenPlan`  | -        |     1000 |   1000 |

### 说明

* 免费 / 默认用户适合基础测试和低频调用。
* 企业认证用户拥有更高的基准文本调用能力。
* Token Plan 用户适合生产环境、高频请求和智能体工作流。

## 4. 图片模型 RPM 限制

图片模型 RPM 按分辨率区分。通常分辨率越高，RPM 越低。

| 模型类型 | 用户类型         | 分辨率 / 规格 | 允许发起 RPM | 实际 RPM |
| ---- | ------------ | -------- | -------: | -----: |
| 图片模型 | `default`    | 1K       |       30 |     20 |
| 图片模型 | `default`    | 2K       |       20 |     10 |
| 图片模型 | `default`    | 3K       |        2 |      1 |
| 图片模型 | `default`    | 4K       |        1 |      1 |
| 图片模型 | `enterprise` | 1K       |       60 |     40 |
| 图片模型 | `enterprise` | 2K       |       40 |     20 |
| 图片模型 | `enterprise` | 3K       |        2 |      1 |
| 图片模型 | `enterprise` | 4K       |        2 |      1 |
| 图片模型 | `TokenPlan`  | 1K       |      120 |    100 |
| 图片模型 | `TokenPlan`  | 2K       |      120 |     80 |
| 图片模型 | `TokenPlan`  | 3K       |        2 |      1 |
| 图片模型 | `TokenPlan`  | 4K       |        2 |      1 |

### 说明

* 图片模型 RPM 按分辨率区分。
* 分辨率越高，消耗的计算资源越大，因此 RPM 通常越低。
* Token Plan 用户在 **1K / 2K** 档位下拥有更高的图片生成能力。
* 当前 **3K / 4K** 档位限制相对更严格。
* 对于图片生成，`1K`、`2K`、`3K`、`4K` 是与支持的 `ratio` 配合使用的输出档位，不等同于 1080p、1440p 或 UHD 等显示器分辨率名称。

### 图片尺寸档位

为了获得可预期的输出尺寸，建议使用档位式 `size`，并配合支持的 `ratio`。

例如：

```json theme={null}
{
  "size": "2K",
  "ratio": "16:9"
}
```

上面的请求使用 **2K** RPM 档位，并返回 `2624x1472`。

如果请求 `1920x1080` 或 `2560x1440` 这类不受支持的精确尺寸，服务可能会自动标准化到最接近的输出档位和宽高比。例如，16:9 请求可能会被标准化为 1K 输出尺寸 `1312x736`。

| Ratio  | 1K          | 2K          | 3K          | 4K          |
| ------ | ----------- | ----------- | ----------- | ----------- |
| `1:1`  | `1024x1024` | `2048x2048` | `3072x3072` | `4096x4096` |
| `3:4`  | `864x1152`  | `1728x2304` | `2592x3456` | `3456x4608` |
| `4:3`  | `1152x864`  | `2304x1728` | `3456x2592` | `4608x3456` |
| `16:9` | `1312x736`  | `2624x1472` | `3936x2208` | `5248x2944` |
| `9:16` | `736x1312`  | `1472x2624` | `2208x3936` | `2944x5248` |
| `2:3`  | `832x1248`  | `1664x2496` | `2496x3744` | `3328x4992` |
| `3:2`  | `1248x832`  | `2496x1664` | `3744x2496` | `4992x3328` |
| `21:9` | `1568x672`  | `3136x1344` | `4704x2016` | `6272x2688` |

如果生产场景需要 `1920x1080` 或 `2560x1440` 等精确显示器画布，建议使用 `size: "2K"` 和 `ratio: "16:9"` 生成，再在下游裁剪或缩放到最终尺寸。

## 5. 视频模型 RPM 限制

视频模型除 RPM 外，还受 **每日视频秒数配额** 限制。

| 模型类型 | 用户类型         | 分辨率 / 规格 | 允许发起 RPM | 实际 RPM |
| ---- | ------------ | -------- | -------: | -----: |
| 视频模型 | `default`    | -        |        2 |      1 |
| 视频模型 | `enterprise` | -        |        2 |      2 |
| 视频模型 | `TokenPlan`  | -        |        6 |      5 |

### 说明

* 视频生成成本较高，因此 RPM 通常低于文本和低分辨率图片。
* Token Plan 用户当前视频订阅配额为 **每天 500 秒**。
* 视频模型同时受 **RPM 限制** 和 **每日秒数配额** 限制。

***

## 6. RPM 与订阅配额的区别

### RPM 限制

RPM（Requests Per Minute）表示每分钟可处理的请求数，用于控制请求频率。

例如：

* 免费 / 默认用户的视频模型为 **1 RPM**
* 企业认证用户的视频模型为 **2 RPM**
* Token Plan 用户的视频模型为 **5 RPM**

### 订阅配额

订阅配额控制某个时间窗口内的总可用使用量。

例如：

* Starter 用户每 5 小时可使用 **1,500 次** `agnes-2.0-flash`
* Token Plan 用户每天可生成 **4,000 张图片**
* Token Plan 用户每天可生成 **500 秒视频**

### 两种限制同时生效

用户必须同时遵守：

1. RPM 限制
2. 订阅配额限制

例如，Token Plan Pro 用户虽然文本模型支持 **1000 RPM**，但仍然受 **每 5 小时 30,000 次** 和 **每周 300,000 次** 的配额限制。

## 7. API 密钥类型

| API 密钥类型      | 适用用户          | 限制方式                     |
| ------------- | ------------- | ------------------------ |
| 免费 / 默认密钥     | 所有用户          | 使用免费 / 默认 RPM 池          |
| 企业认证密钥        | 企业认证用户        | 使用企业认证 RPM 池             |
| Token Plan 密钥 | Token Plan 用户 | 使用 Token Plan RPM 和订阅配额池 |

不同类型的密钥可以独立使用。

***

## 8. 限制池说明

限制按 **密钥类型** 共享，而不是按每个单独的密钥分别计算。

创建多个相同类型的密钥，不会增加总 RPM 或总配额。

### 示例

| 场景                   | 限制方式                        |
| -------------------- | --------------------------- |
| 创建 2 个免费密钥           | 共享同一个免费 / 默认 RPM 池          |
| 创建 2 个企业认证密钥         | 共享同一个企业认证 RPM 池             |
| 创建 1 个 Token Plan 密钥 | 共享同一个 Token Plan RPM 和订阅配额池 |

<Warning>
  API 密钥用于访问控制、应用隔离和环境管理，不用于叠加使用限制。
</Warning>

## 10. 常见问题

### Q1：创建多个 API 密钥会增加 RPM 或配额吗？

不会。

相同类型的多个密钥共享同一个限制池。\
创建更多密钥不会增加总可用 RPM 或总配额。

***

### Q2：Token Plan 用户还能使用免费密钥吗？

可以。

Token Plan 用户仍然可以使用免费 / 默认密钥。\
免费密钥和 Token Plan 密钥使用不同的限制池。

***

### Q3：Token Plan 用户也可以成为企业认证用户吗？

可以。

完成企业认证后，用户可以同时使用：

* 免费 / 默认密钥
* 企业认证密钥
* Token Plan 密钥

每种密钥类型按照各自的限制池独立生效。

***

### Q4：企业认证用户会自动获得 Token Plan 配额吗？

不会。

企业认证只提供更高的基准 RPM 限制。\
Token Plan 配额仅在订阅 Token Plan 后生效。

***

### Q5：图片配额按请求计数还是按图片数量计数？

当前按 **生成的图片张数** 计数。

Token Plan 用户当前可生成：

* `agnes-image-2.0 / 2.1-flash`
* **每天 4,000 张图片**

***

### Q6：视频配额按请求计数还是按视频时长计数？

当前按 **生成的视频时长** 计数。

Token Plan 用户当前可生成：

* `agnes-video-v2.0`
* **每天 500 秒视频**

视频 RPM 限制也同时适用。

***

### Q7：不同类型的密钥之间会共享限制吗？

不会。

限制仅在 **相同类型的密钥之间共享**。

例如：

* 免费密钥使用免费 / 默认 RPM 池
* 企业认证密钥使用企业认证 RPM 池
* Token Plan 密钥使用 Token Plan RPM 和订阅配额池

不同类型之间互不共享。

***

## 11. 总结

Agnes AI 当前支持三种主要访问类型：

* 免费 / 默认用户
* 企业认证用户
* Token Plan 用户

它们在 **文本模型、图片模型、视频模型** 上拥有不同的 RPM 限制。

其中，Token Plan 用户除更高 RPM 外，还拥有额外的订阅配额，包括：

* 文本请求次数配额
* 图片生成张数配额
* 视频生成秒数配额

相同类型的多个密钥共享同一个限制池。\
不同类型的密钥使用独立的限制池。

本文档中的所有数值为当前公开参考值，未来可能调整。
