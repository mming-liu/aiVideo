## 1. 配置合同（`shared/config.py` + `.env.content` 注释模板）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `MERGE_BGM_ENABLED` | `0` | 唯一开关；关闭时编译期**完全不碰**滤镜图 |
| `MERGE_BGM_PATH` | 空 | 本地 `.wav/.mp3/.flac` |
| `MERGE_BGM_BASE_GAIN_DB` | `-16.0` | 无人声段增益 |
| `MERGE_BGM_DUCK_GAIN_DB` | `-26.0` | 有人声段增益，必须 `<= BASE` |
| `MERGE_BGM_FADE_IN_SEC` / `FADE_OUT_SEC` | `1.0` / `2.0` | 成片首尾淡入淡出 |
| `MERGE_BGM_ATTACK_SEC` / `RELEASE_SEC` | `0.15` / `0.35` | 压低/恢复的线性斜坡 |

`shared.config.bgm_config()` 是唯一读数入口，开启时校验：数值有限、时长为非负、
`duck <= base`、路径非空。**开关打开但文件缺失/格式不支持/增益倒挂**：
- `step04_merge.main._encode_settings()` 在编码前抛 `RenderError(code=bgm_*)`；
- `apply_bgm_to_graph()` 再核一次文件存在（`BgmError`），确保不经由其它入口漏过。

## 2. 实现（`step04_merge/bgm_mix.py`）

1. **循环与采样率**：输入加 `-stream_loop -1`，分支内 `aresample=48000` +
   `aformat=fltp:stereo` + `atrim=duration=<成片时长>`，短 BGM 自动铺满；
2. **确定性包络**：`voice_intervals()` 从 `MergeTimeline.windows` + `audio_tracks`
   （`shot_tts` 按镜头窗口、`narration` 按起止秒）收集人声区间并合并 →
   `duck_segments()` 按 `attack/release` 外扩并裁到 `[0, total]` → 重叠段再合并 →
   `envelope_expression()` 生成嵌套 `if(lt(t,...))` 线性斜坡（无抽吸、可毫秒级测量）。
   表达式超过 12000 字符时按「间隔最小的一对」确定性合并（长片防命令行超长）；
3. **混音**：`amix=inputs=2:duration=first:normalize=0:weights=1 1`——BGM 增益已在
   自己的包络里，`normalize=0` 保证不二次衰减人声；
4. **接线**：`backends/ffmpeg.py::compile_graph()` 在旁白混音之后追加 BGM 输入与
   分支；`settings.bgm is None` 时该段一行不执行 ⇒ 滤镜图与历史**逐字节一致**；
5. **音效钩子**：`resolve_local_sfx(audio_cue, sfx_dir)` 纯数据映射（找不到返回
   `reason`，零网络请求），本包只提供接口，未接入主流程。

## 5. 残余

1. **未接 `env_guard`**：非法 BGM 配置在 `_encode_settings()`/渲染前才失败，`--check`
   不会提前报；要提前的话需要把 `MERGE_BGM_*` 纳入一致性规则（下轮可加）。
2. **无侧链压缩**：按计划用「基于时间轴的确定性包络」而非 `sidechaincompress`
   （后者不可离线精确断言，且不同 FFmpeg 版本行为有差）。
3. **`resolve_local_sfx` 未接入主流程**：计划只要求预留纯数据钩子；真正接入需要
   镜头级 `audio_cue` 字段与音效库治理。
4. 淡入淡出在包络之后叠加（`afade`），与人声段的压低互不影响；若 BGM 首尾恰好
   落在人声段内，淡入会让该段更轻（可接受，且与商业成片惯例一致）。
