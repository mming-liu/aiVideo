## 3. 遇到的问题

1. **工具 120s 程序超时**：前台生成被整体杀掉，尾帧请求在途；改后台 job 后续跑，未重复生成已有图。
2. **门禁指纹漂移**：`step01_script_gen/validation.py` 加入运镜一致性告警后，规则指纹 `246f8873 → 2d9dda15`，`production_context --run` 报 `upstream_gate_failed`；用 `--refresh-gate` 重签四份门禁产物（脚本 sha/revision 未变）。
3. **OpenCode Go 端点用错**：`/inference/openai/v1` 走账户余额 → 402；正确为 `/zen/go/v1` + `x-opencode-session` + 明确 User-Agent。
4. **视觉复核误读**：缩略全图误判“首帧已在吹”；裁到听香/伞又误判重抽“一开始就在吹”。按主体定位裁切后：0.1s 明显空隙、3.0s 变小、5.7s 贴住嘴唇。
5. **船原地漂**：首尾帧位移太小 + `camera_movement=固定机位`，图生视频插值不出行进。
6. **听香未侧身、老农未出现**：后者源于 `camera_movement=固定机位` 与 `motion_desc=镜头掠过` 的稿子矛盾。
7. **计划/实际不一致**：plan 报 4 张肖像，实跑按文件存在性只生成缺失的 `face`；`writes` 是上限。
8. **肖像方向不一致**：`base/side/back` 横版 2560×1440，`face` 竖版 1440×2560。
9. **模型可用性**：`gemini-3.5-flash-lite`、`gpt-5.4-nano` 在 Go 端点 unavailable；`grok-4.7` 对箫距判断与多数相反。
