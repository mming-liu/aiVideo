# X5 首批交付：Studio 断点面板 + 点击锁保帧（2026-11-17）

对应进阶方向 X5（Studio UI 一键审片、锁图与批授权闭环）。**零模型调用**；
不改任何正式产物（锁保只在显式点击时写标记文件）。

## 1. 交付内容

### 1.1 CP1–CP4 断点可视化（`tools/studio_server.py` + `tools/studio_ui/index.html`）

- 新增 `Studio.checkpoints()`：只读 `snapshots/_checkpoints.json`
  （`shared.step01_checkpoint` 写入的指针索引），按阶段给出
  `present / key / path / revision / written_at / round`，并附 `latest`。
  不猜"最新目录"、不读 mtime。
- `overview()` 返回值新增 `checkpoints`，于是页面**每 5 秒轮询**就能反映
  "跑到哪一步"，不需要再去翻目录。
- `GET /api/checkpoints` 单独暴露（供脚本/看板消费）。
- UI：Step01 页顶部新增「断点（CP1–CP4）」卡片，四个 badge 显示
  ✅/⚪ 与 `written_at`/`revision` 悬浮提示。

### 1.2 点击锁保帧（`.lock_frame`）

- 新增 `Studio.frame_lock(shot, kind, locked)`：
  - `kind=""` → 整镜标记 `.lock_frame`；
  - `kind="ff"/"lf"` → `.lock_frame_first_frame` / `.lock_frame_last_frame`；
  - 解除只删对应标记，**不碰原图与哈希**。
- 标记名**不另起一套**：直接读 `shared.vimax_bridge._PROTECTED_FRAME_MARKER`，
  与生成链 `_frame_is_protected()` 同源（QC critical 不删原图、`--force` 不覆写）。
- `review()` / `overview()` 的每帧新增 `locked` 字段，`review()` 另给整镜
  `lock` 汇总，UI 按钮据此在「🔒 已锁保（点击解锁）」与「🔓 锁保此帧」之间切换。
- `POST /api/frame/lock` `{shot, kind, locked}`。
