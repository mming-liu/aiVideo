## S05：legacy 现场校准

冻结现场 `.tmp/s14/exec/cmp_ch1_vsplit.json`（SHA-256 见 `s05_calibration.json`），父 f10，子 f10.1/f10.2，M 回答 `c7bf366cb4df849e7`。

| 核对项 | 读数 |
|---|---|
| 原文 | 「公子爷吃醉了酒，险些跌落水中…尖叫起来。」与「…生意上的事情急需**公子爷**赶回去处理」是两段连续原文，相隔 117 字 |
| 父主张 | 「张十三对庄仆谎称公子醉酒，并称有生意急事要回城」：两个分句；「要回城」缺主体；证据只引第一句 |
| 影子原子性 | `fact_atomicity_composite_uncovered`：两个分句都无连续证据直接覆盖 |
| 子主张 | f10.1、f10.2 的证据都逐字命中原文；f10.2 把回城主体落实为公子（与原文一致） |
| 受限拆分合同 | 冻结子主张被拒（`split_child_claim_not_covered` ×2、`split_claim_union_mismatch`）；逐字切开父主张则通过，但第二分句仍缺主体 |
| M | 输入身份 `inputs_digest` 重算与记录一致；M 只收到父/子主张，按父主张字面把「要回城」读成张十三，判 partial——在其输入下成立 |

结论：**来源缺陷**（复合 + 缺主体 + 证据不全），不是 M 误拒。拆分修不了它：合同只接受父主张的逐字片段，会原样继承缺主体；
改写子主张（不论是否忠于原文）都被拒。修法应在来源生产者改父主张（下一包），本包不改 M、来源保护或提交门，影子结果不注入硬门。
匿名回归 `tests/step01_script_gen/test_s05_source_split_calibration.py` 固定了这三点。

## S06：分镜请求里的声音时长

`render_voice_timing(plan)` 读 `plan_feasibility.voice_entry_costs`（与计划验收、单镜判据同一入口），在执行契约末尾给出：

- 每条声音：台词 `播出正文约 X s；带「说话人道：」后约 Y s`（对白前缀余量另列）、说话人；旁白 `播出正文约 X s`；
- 全章合计（台词 + 旁白）、正片合法区间与单镜上限；
- 画面与声音同时发生，剩余秒数是无声镜头与停留的上限，不是必须填满；
- 每镜 `duration_sec` 须容纳本镜所有声音按播出顺序相加、`motion_desc` 时段终点、最后关键帧 `t_sec`。

不给逐镜最短时长（生成前没有镜头分配），不改任何声音文本、动作时段或时长硬门。测试从 `gen_spy_script` 实际发送的请求读取。
这一项对真实生成时长的效果**未验证**。
