## 六、还留了什么

1. **T3 需产品裁决**：确定性 finding 是否可以直接决定 severity 下限/blocking？如果接，必须明确「哪些码、下限是什么、哪些降级豁免仍然有效」，并把它放在 blocking 统计之前。当前默认行为未改。
2. **`ADDED_DIALOGUE` 未接通生产对照源**：生产路径 `audit_adjudication.py:575`（`build_shadow_report`）与 `:208`（`deterministic_checks`）都调用 `scan_script(script)`，**没有传 `source_text`**；`main.py:2981` 调用 `build_shadow_report` 时也只传了 `context`。因此该码目前在真实审计/裁决路径上不会产出，只有测试或直接调用会触发。
3. **`ADDED_DIALOGUE` 覆盖有限**：只识别引号台词或「说话人 + 冒号」的显式台词；无引号、无说话人前缀的纯叙述不判定；`source_contains` 是归一化后整句包含，标点/空格变体会被容忍，极短台词可能偏松；它也不能区分「新增」与「合法改编」，只能回答「对照源里有没有」。
4. **T1 双重否定/习语边界**：`_NEGATION_MARKERS` 含「不」「无」，前缀判断会把「不得不拿起」「无奈拿起」误当否定 → `_acquire_in` 返回 `False` → 可能**多报** `PROP_STATE_CHAIN`（仅 shadow，不阻断）。当前未做语义级消歧。
