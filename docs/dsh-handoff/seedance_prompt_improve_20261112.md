## A. 数据源（官方 / 准官方，已核实）

> 注：用户给的火山方舟 Gallery `https://ark.volcengine.com/ark/gallery` 是 JS 单页应用，WebFetch 抓不到内容；以下为 Gallery 案例的真实来源——火山方舟官方 Seedance 提示词指南（1.0/2.0/2.5）及与其一致的权威复刻，均引用 ByteDance/Volcengine 官方 spec。

1. **火山方舟 Doubao Seedance 2.5 提示词指南** `https://docs.volcengine.com/docs/82379/2607689`
   - 进阶公式：`精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件`
   - **视频参考（关键）**：白模/渲染「文本中写明希望参考白模视频中的什么元素」「参考 [视频 1] 的运镜、动作…」「参考 [视频 1] 的光影变化」；叠加参考图时需写明对应关系「将 [图片 1] 中穿灰色衣服的男人对应 [视频 1] 中的红色模型」
   - 转场写清触发点与方式（「第 5s 快速向左横移转场(向左擦除+自然叠化)」）
   - 动作优先概括性描述，只在记忆点写细节；表情写描述性语句（「津津有味地吃饭」→「脸上带着满足的笑容,大口地吃饭」）
   - 多宫格分镜更适用 15 个以下，避免脏/锐化分镜图、避免图面写过多文字

2. **火山方舟 Doubao Seedance 2.0 提示词指南** `https://www.volcengine.com/docs/82379/2222480` 与 `https://www.volcengine.com/docs/ark/seedance-2-0-prompt-guide`
   - **运镜核心约束（重要，纠正方向）**：「注意 一个镜头里尽量只指定 1 种运镜方式，不要同时要求推拉摇移，会增加画面的不稳定性。」
   - **参考指代**：「将 图片1 中穿红色连衣裙、戴草帽的女人定义为 主体1」；「@图片 1 中的女孩作为主角,@图片 2 作为宿舍场景风格参考,参考 @视频 1 的运镜方式。」
   - 素材可含 @图片/@视频/@音频；视频参考句式「参考 视频1 的[参考维度],生成...」；编辑/延长视频用「视频1」直接指代而非「参考」（避免误判为参考任务）
   - 画质/风格/约束词模板：画质「高清,细节丰富,电影质感,色彩自然,光影柔和」；约束「保持无字幕」「不要生成Logo」「不要生成水印」
   - 实战案例：多镜头剧本用「镜头 1 / 镜头 2 / 镜头 3」分镜，每镜一个中景/近景/全景 + 一个运镜（跟拍/切/拉远定格），全程「高清电影纪实风,色调温暖,光影柔和;人物面部稳定不变形,动作自然流畅,无卡顿无闪烁」

3. **Seedance 2.5 视频编辑/参考指南** `https://www.seedance.tv/zh/blog/seedance-2-5-video-editing-guide` / `https://www.seedance.tv/zh/blog/seedance-2-5-reference-guide`
   - **多运镜只在「单条连续长镜头 + 时间窗」下成立**：京剧案例「生成 16:9 电影宽屏，**一条连续镜头**，保持所有运镜流畅、避免一切切剪。0-5s: 近景环绕上身为中景…6-10s: 中景环绕并跟随水袖…11-20s: 带入武生空中翻腾…最后从中近景缓慢拉远至全景。」——这是**带时间窗的连续镜头**，不是无结构多运镜词。
   - 镜头术语表：靠近=缓慢推进(slow dolly in)；远离=拉远(dolly out)；环绕=顺时针环绕30度/四分之三弧线；横移=左横移/右摇摄；垂直=仰角抬升/俯角下降；固定=静态锁定镜头；增强真实感=轻微手持漂移
   - 「每个节拍仅使用一种镜头运动，并对应一个核心主体动作」「若镜头跳切，确保每镜仅含一个运镜动作」「避免相互冲突的镜头运动（如固定机位 + 快速环绕）」
   - 参考能力上限（2.5）：单次最多 30 张参考图 / 10 个参考视频 / 10 个参考音频

4. **Seedance 2.5 I2V 指南** `https://seedance.tv/blog/seedance-2-5-image-to-video-guide-2026`
   - I2V 提示词三要素：① 运动（什么动、怎么动，要具体）② 镜头（运镜+速度，如 slow push-in from medium to close-up）③ 氛围（声音/光变/天气/粒子）
   - 不要把图里已可见的内容重描（「模型有图，你的提示词是导演指令不是美术描述」）

5. **通用公式（多来源一致）**：主体+动作+环境+光影+运镜+风格+画质+约束；**≤500 中文字符上限**（超出被激进摘要、丢细节）；首句权重最高，硬约束/主体身份/关键动作/主场景前置；避免抽象赞美（「很有电影感」）与相互冲突指令；一次只调一个变量对比。

## B. 我方现有链路分析（来自对已跟踪代码的审阅，非假设）

已确认我们在用火山方舟 Seedance（`_video_gen/volcengine_provider.py` 与 `agent_plan_provider` 两套 provider），且已落地多条官方推荐实践：

- **500 字压缩**：`_seedance_compress_prompt` 高/中/低权重句优先、参考块整块保留、超限硬阻断——已应对长度上限。

- **R2V 参考图 + 收敛**：`cap.supports_reference_image` 门控 + `ref_compose` 无损拼表。
- **跨镜连续性**：`continuity.py` 提取上条视频**尾帧 PNG** 做 I2V 尾帧接续（Mode B）。

### 缺口与可落地改进（按价值排序，已做自我纠正）

- **T1（高价值·真缺口）原生视频参考未接上**：我们 `reference_paths` 字段名写"参考图/视频"，但 provider 实际**全当 image 发**（`volcengine_provider._image(ref_path,"reference_image")` + `_encode_media` 默认 `image/png`）。Seedance 2.0/2.5 支持 `@视频` 参考（运动/运镜/光影），2.5 单次可达 10 个视频参考。目前跨镜连续性只靠尾帧 PNG 近似，非原生视频参考。→ **接入：识别视频型参考、按 mime 用 `video/mp4` 等正确编码、生成「参考 [视频 N] 的运镜/动作」指代文案、加 `supports_video_reference` 能力位校验、为跨镜连续性提供视频参考路径**（替代/增强尾帧 I2V）。价值高 / 难度中。
- **T2（中价值）时间窗结构化长镜提示词缺失**：官方 2.5 用 `0-5s / 5-12s / 12-20s / 20-30s` 时间窗描述单条连续长镜。我们的 prompt 多为分镜列表、缺时间窗结构。→ 对「单条连续镜头 + 多节拍」场景生成时间窗分段的运镜/动作描述（低权重段，压缩时可被砍）。价值中 / 难度低-中。
- **T3（中价值·需谨慎）运镜门禁判定过粗（含自我纠正）**：`video_prompt_quality` 的 `video_camera_stacking` 当前对"单镜出现多个运镜词"直接记警告。官方口径是「**一个镜头尽量只 1 种运镜**」+「**跳切时每镜仅 1 运镜**」+「**避免相互冲突运镜（固定机位+快速环绕）**」，但**单条连续长镜 + 时间窗**允许顺序多运镜（2.5 京剧案例）。→ 故**不应一刀切放开**，而应变精：仅当①运镜相互矛盾（如 locked + orbit）/ ②多运镜但无时间窗或顺序标记时警告；允许「连续镜头 + 时间窗」的顺序多运镜通过。**这是对我上一轮"放宽"建议的纠正**——目标是让门禁与官方口径对齐，而非弱化质量。
- **T4（低-中价值·廉价为先）氛围/情绪自然语言润色偏弱**：官方强调用描述性语句写情绪（「脸上带着满足的笑容」而非「很开心」）和类型化氛围（欧洲文艺电影/复古香港电影/恐怖片）。我们主要靠 `【色彩氛围】` 结构化标签。→ 在 `prompt_builder` 加一层类型化自然语言 enrichment（低权重段）。价值中 / 难度低。
- **暂不优先**（写实小说改编场景用不上）：多风格直出（2D/3D/体素/毛毡/漫画）、多宫格分镜图参考（我们本就不主打）、Logo 贴片参考。
