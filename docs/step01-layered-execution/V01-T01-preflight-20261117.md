## 2. T01 声音核对（零调用）

| 项 | 读数 |
|---|---|
| 声音模式 | `VIDEO_MODEL_VOICE` 未设（默认 `1`）；`MERGE_AUDIO_MODE` 未设（默认 `native`） |

| 解出的声音合同 | `native_voice=True` / `tts_required=False` / reason=`model supports native audio` |
| 现有音频缓存 | `chapter_001/audio/` **0 个文件** |

| 对白 | `dialogue_lines` **1 条**（约 20 字），绑定 **shot 12** |

### 2.1 关键问题：声音合同与实际模型不一致

`resolve_audio_policy()` 依据 `active_video_model()` 判能力，而该函数在
`VIDEO_PROVIDER=volcengine` 且 `VIDEO_MODEL` 未设时返回 **1-5-pro**（有声）；
真正下发请求的模型却是 **1-0-pro**（无声）。后果：合同判 `native` ⇒ Step 04 **不混 TTS**
⇒ 132 字旁白与 1 条对白**没有声音来源**。

**这不是"待验证"，是代码可读出的确定性冲突**：能力查询与请求组装用了两个模型身份。

### 2.2 待合成 SpeechUnit 清单（若改走 TTS）

| # | 类型 | 落点 | 说话人 | 文本量 |
|---|---|---|---|---|
| 1–5 | 旁白 | 5 个带 `narration_segment` 的镜头 | 旁白（无角色） | 合计 **132 字** |
| 6 | 对白 | shot 12（`plan_refs.lines=[1]`） | 台词内声明 | **约 20 字** |
| 合计 | | | | **约 152 字** |

- TTS 费用口径：按 provider 的**每千字符单价 × 0.152 千字符**；单价未在本仓声明，
  需按实际 provider 报价确认。合成前需先决定**声音归属**（旁白是否单人、对白说话人），
  按现有声音合同处理，不在此处代定。
