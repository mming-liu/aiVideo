# 规格选择（步骤 6）

拓扑固定为单机（1 ECS + EIP + VPC + SG）。通过 AskUserQuestion 让用户选择 ECS 规格。

---

## ECS 规格选项（AskUserQuestion）

| 选项 | 规格 ID | 配置 | 参考价 |
|------|---------|------|--------|
| 入门型 | `ecs.e-c1m1.large` | 2C2G | ≈ ¥0.10/时 |
| 通用型 | `ecs.e-c1m2.large` | 2C4G | ≈ ¥0.31/时 |
| 性能型 | `ecs.e-c1m2.xlarge` | 4C8G | ≈ ¥0.62/时 |

---

## 选择建议

| 项目类型 | 推荐规格 |
|----------|----------|
| 静态网站 / 轻量 API | 入门型 2C2G |
| 全栈应用（静态+应用 + 小型 DB） | 通用型 2C4G |
| Java 应用 / 重计算应用 | 性能型 4C8G |

---

## 产出

- `INSTANCE_TYPE`：用户选择的 ECS 规格 ID

---

## 注意事项

- 参考价仅供展示，实际价格以步骤 9 询价结果为准
- 规格影响后续步骤 8（库存检查）的可用区匹配
