# 短剧「让画面动起来」技巧 参考（评估记录）

> 来源：抖音短剧拍摄技巧教学（2026-08 用户提供）。
> 结论：**存 reference，不新建 skill、不改规则**（用户决策 08-12）。核心原则已被规则 21/26
> 与 advanced-camera-movement / situation-camera skill 覆盖，仅记录**具体可落地的模式**供
> prompt 编写与未来校验参考。

## 核心原则

**让画面「动起来」**——摄影机动 / 人物动 / 两者同时动，是短剧有节奏、更紧凑的关键。
固定镜头 + 人物站定不动 = 画面平、无紧张感（即使是同样情节）。

## 正反案例（教程原文）

| 场景 | 反例（静） | 正例（动） |
|---|---|---|
| 宴会冲突 | 全程固定镜头、人物位置无变化 → 无紧张感 | 先**手部特写**→**上摇到人物中景**→**横摇带出反派**→**镜头跟随士兵进入**，镜头持续运动，紧张感立刻提升 |
| 军营传令（边关告急） | 人物站定不动、对话时位置固定 → 与紧急情节不匹配 | 人物**走动中说台词 + 镜头跟随移动**，画面紧迫感与情节节奏贴合 |

## 本流水线已有的对应

- **运镜服务叙事**：规则 21（固定机位是基础；一镜一动作/对话；禁无效运镜）+ 规则 26（高级运镜：侵入式推进/极速鞭甩等）。
- **运镜词库**：advanced-camera-movement skill（六组基础→高级运镜对照）、situation-camera skill（18 种情景剧运镜）。
- **节奏校验**：validation `_check_dwell_time`（静态/对白镜停留时长）、`_check_camera_upgrade`（高张力镜才提示升级运镜）、`_check_camera_movement`（一镜一运镜）。

## 可落地的增量模式（写 prompt 时用）

1. **高张力对白镜优先让画面动起来**：冲突/告急/对峙类场景，对白不要「两人站定正反打」——
   改「人物边走边说台词 + 中景跟拍」或「镜头缓推/横摇贯穿台词」，画面节奏贴合情节张力。
2. **镜头持续运动串场**（一个镜头内）：手部特写 → 上摇到人物中景 → 横摇带出反派 → 跟拍
   士兵进入。用镜头移动替代切镜来递进空间/人物关系。
3. **低张力对白/抒情镜保持静止**：规则 44（静态停留）+ rule 21「固定机位是基础」仍适用——
   「动起来」只对高张力/冲突/告急场景，静止是低张力镜的默认，避免每镜都花式运镜。

## 与 validation 的关系

`_check_camera_upgrade` 已对高张力镜头（打斗/对峙/追逐/离别等）提示升级运镜。若未来要
强化，可给该检查补一个触发场景：「高张力对白镜（narration 含冲突/告急/对峙词）且 prompt
全固定机位 → 提示动起来」。本次**未实施**，仅记录。
