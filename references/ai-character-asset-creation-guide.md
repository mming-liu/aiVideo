# AI漫剧角色资产全流程创建指南（视频内容+工具优化）

## 一、视频核心方法论（角色一致性关键）

### 1. 基础图优先策略
**错误做法**：直接生成三视图，导致角色细节、光影、质感不一致，缺乏真人感。

**正确步骤**：
- 先创建**单张基础全景图**，锁定核心特征：
  - 外观：脸型、发型、服装、身材比例（如24岁168cm警校女生，鹅蛋脸+深色锁骨发+藏青工装）
  - 质感：真实皮肤纹理、轻微毛孔、布料褶皱、袖口磨损、鞋面灰尘
  - 光影：主光45°照射+补光+轮廓光，色温5500K，确保阴影统一
- 提示词强化真实感：添加"轻微电影胶片颗粒""真实镜头微反差""轻微自然暗角"，避免过度滤镜。

### 2. 参考生成分支
基础图确认后，上传作为参考，生成：
- 面部特写（锁定五官细节）
- 正面/侧面/背面全身照（三视图）
- 提示词强制约束："脸型、发型、服装、身材比例、光源全部一致"

### 3. 资产规范管理
- 命名格式：`剧本名称-人物资产-角色名称`（如"废弃医院失踪案-人物资产-张青"）
- 存储：将基础图+三视图存入文件夹，后续分镜/视频直接调用，避免重复生成。

## 三、提示词工程优化技巧（结构化模板）

### 1. 万能人物Prompt公式
```
[风格/画风] + [主体身份/年龄/性别] + [外貌细节] + [服装配饰] + [光影氛围] + [质量标签]
```

**示例**：
```
电影写实风格，24岁168cm中国女性，刚从警校毕业的年轻辅警，鹅蛋脸+深棕色眼睛+深色锁骨发，穿着藏青工装夹克+黑色长裤，主光从右前方45°照射，左侧补光，后上方轮廓光，色温5500K，真实皮肤纹理，轻微胶片颗粒，8K高清，电影级质感。
```

### 2. 一致性强化技巧
- 强制统一：在提示词中重复"与参考图一致的脸型/发型/服装/光源"
- 负面提示词：排除"模糊、畸形、低分辨率、塑料皮肤、过度滤镜"
- 分步生成：先基础图→再特写→再三视图，每步锁定特征

## 四、实战避坑指南

1. **避免风格漂移**：优先使用同一工具生成所有资产，切换工具时需重新上传参考图。
2. **细节修正**：AI生成后，用PS微调服装褶皱、光影细节，确保三视图统一。
3. **资产复用**：将基础图+三视图导入ArcReel等漫剧工作台，自动生成全剧角色资产库。
4. **版权合规**：使用正版素材训练LoRA，避免商用侵权风险。
