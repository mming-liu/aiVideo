# AI 人物面部去塑料感提示词库（5XL-AI 整理）

> 来源：2026-08-05 从图文教程整理，专治 AI 人像"塑料脸/硅胶感/过度磨皮"。
> 适用范围：人物肖像、面部特写、首帧/尾帧人脸画面。
> 与 material-realism（通用物体材质）互补——本库只针对**人脸皮肤**。

## 一、基础核心提示词（直接复制添加即可）

```
可见毛孔细纹，自然红润感，面部要有明暗变化，不要均匀受光，有光影颗粒，灰尘噪点，不要干净无层次
```

一句话概括：**「有毛孔 + 有红润 + 有明暗 + 有颗粒」** 四个反塑料要素。

## 二、强化补充提示词（可叠加使用）

**皮肤细节类**：
```
真实皮肤纹理，轻微油光质感，细小汗毛，少量面部小痣，真实唇纹，眉毛根部细节
```

**光影结构类**：
```
侧光照明，柔和明暗过渡，苹果肌自然起伏，脸颊阴影层次，鼻翼到脸颊真实过渡，不要过度磨皮，不要完美对称
```

**氛围质感类**：
```
自然窗光，轻微呼吸感，眼神自然停留，不要脸颊一整片发亮，不要夸张五官，不要塑料皮肤
```

## 使用位置

- **角色肖像**：`vimax/agents/character_portraits_generator.py` 肖像 prompt 面部段
- **首帧/尾帧特写**：分镜人脸特写镜头（prompts.py 5.3 古风人物公式的「皮肤必须强调真实纹理」处，可升级为完整段落）
- **与脸型库配合**：先选脸型（[[ai-face-shapes-library]]），再加去塑料段——脸型定轮廓气质，去塑料段定皮肤真实感
