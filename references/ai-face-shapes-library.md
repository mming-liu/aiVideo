# AI 人物脸型分类提示词库（5 种脸型）

> 来源：2026-08-05 从视频教程完整提取的 5 种 AI 脸型提示词，每种含完整 Prompt + 核心特征。
> 用途：人物肖像/首帧/分镜 prompt 中按角色气质选脸型，差异化塑造男女主与配角。

| --- | --- | --- | --- |

| 天鹅脸 | 修长脸型、高鼻梁、清晰下颌线、贵气 | 优雅高级、端庄 | 大家闺秀、权贵之女、名门正妻 |

## 1. 雀斑脸

**核心特征**：雀斑 + 自然皮肤 + 浅色眼睛 + 野生感

**完整 Prompt**：
```
一位年轻欧美女性，雀斑少女脸，脸上有自然分布的小雀斑，浅色眼睛，
浓密自然眉毛，真实皮肤纹理，轻微晒伤感肤色，自然唇色，没有过度修饰，
清冷文艺感，低饱和色调，电影感复古女王风格，真实肖像摄影，柔和自然光，
胶片质感。
```

**要点**：强调「无过度修饰」「自然」——去精致化，走真实素颜路线。适合需要亲和力、质朴感、异域感的角色。

---

## 2. 天鹅脸

**核心特征**：修长脸型、优雅轮廓、高鼻梁、细长眼、清晰下颌线、贵气感

**完整 Prompt**：
```
年轻女性，天鹅脸，修长脸型，优雅流畅的面部轮廓，高鼻梁，细长眼睛，
清晰下颌线，五官比例精致，皮肤质感高级，没有过重妆容，低饱和妆感，
极简妆容，高级时尚杂志摄影，真实皮肤质感，柔和光影，电影感肖像。
```

**要点**：关键词密度最高的一种——「修长」「优雅」「清晰下颌线」「贵气」。适合名门闺秀、权贵女性、端庄大气的主角/正派女角。

---

## 3. 猫系脸

**核心特征**：细长眼、眼尾上挑、清冷眼神、小巧脸型、轻微攻击性、灵动疏离感

**完整 Prompt**：
```
年轻女性，猫系脸，细长杏眼，眼尾微微上扬，清冷而警觉的眼神，
小巧精致的脸型，干净下颌线，五官立体，高级感冷艳妆容，黑色蕾丝项圈，
灵动又疏离的气质，轻微攻击性，高级时尚人像，真实皮肤纹理，电影感光影。
```

**要点**：冷艳 + 警觉 + 攻击性——适合刺客、杀手、心思深沉的女性角色。注意「黑色蕾丝项圈」是时尚摄影配饰，古风场景需替换为古代配饰（如项圈/璎珞）。

---

## 4. 鹿系脸

**核心特征**：清澈大眼、湿润眼神、柔和脸型、小巧鼻子、温柔无辜感

**完整 Prompt**：
```
年轻女性，鹿系脸，圆润柔和的脸型，大而清澈的眼睛，湿润明亮的眼神，
柔和眉眼，小巧自然的鼻子，饱满苹果肌，自然微笑唇，温柔无辜气质，
清透妆容，无浓妆感，真实皮肤纹理，柔和自然光，清新电影感肖像。
```

**要点**：白月光/清纯女主首选——「清澈」「湿润眼神」「无辜」。与猫系的疏离警觉正好相反，是观众缘最好的一类脸。

---

## 5. 狐系脸

**核心特征**：上挑眼尾、尖下巴、狡黠眼神、微笑唇、精致五官、魅惑感

**完整 Prompt**：
```
年轻女性，狐狸脸，精致小脸，尖下巴，眼尾明显上挑，狡黠灵动的眼神，
眉眼距离偏近，真实精致妆容，低饱和唇色，深色长发，带有攻击性的气场，
妩媚又危险，聪明精明的气质，轻微妖气，精致眼妆，高级电影感人像，
真实皮肤质感。
```

**要点**：妩媚 + 危险 + 妖气——适合妖妃、宠姬、反派美人、心机女角。与猫系同属"攻击性"，但狐系偏魅惑、猫系偏疏离。

## 古风适配补充（供分镜/肖像 prompt 使用）

原始 Prompt 是时尚摄影语境，套用到古风真人时替换以下元素：

| 原始元素 | 古风替换 |
| --- | --- |
| 高级时尚杂志摄影 / 时尚人像 | 古风真人影视剧，电影质感 |
| 现代配饰（黑色蕾丝项圈） | 古风配饰（玉簪/步摇/璎珞/抹额） |
| 低饱和/胶片/复古女王 | 写实古风，冷月清辉/暖烛光 |
| 欧美女性 | 中国古风女子（鹅蛋脸/柳叶眉等按需） |

**示例（古风鹿系白月光）**：
```
年轻古风女子，鹿系脸，圆润柔和的脸型，大而清澈的眼睛，湿润明亮的眼神，
柔和眉眼，小巧自然的鼻子，饱满苹果肌，自然微笑唇，温柔无辜气质，清透妆容，
一袭春衫，头插步摇，真实皮肤纹理，柔和月光，写实古风真人，电影感肖像。
```

## 使用位置

- **角色肖像**：`vimax/agents/character_portraits_generator.py` 的角色特征 prompt 中嵌入脸型词
- **首帧/分镜**：`step01_script_gen/prompts.py` 分镜 prompt 的角色外貌开头段（如"剑眉星目身穿白袍的杨旭"），女主/配角按气质选脸型
- **跨章一致性**：脸型词应写入角色 `static_features`（CharacterBank），保证每章肖像/首帧用同一脸型词
