# aiVideo 深度分析报告与优化方案（聚焦分镜/图片/视频质量，TTS 后置）

## 一、总体诊断（TL;DR）

一个月"不理想"的根因不是单一环节，而是三层问题叠加，且互相放大：

1. **分镜层：LLM 原始输出其实是合格的，被自家的机械后处理层改坏了。** 对比今天同一时刻的 `llm_response_dump_20260828_205130.txt`（原始输出，文字通顺、镜头语言专业）和落盘的 `script_result.json`（破碎文本），破坏全部发生在后处理。
2. **图片层：发给 Seedream 的 prompt 已变成自相矛盾的"法条堆积"（1100+ 字符），模型无法同时满足，只能抽奖。** 美学质量其实很好，输在内容保真度。
3. **视频层：首尾帧时序设计失效（两帧几乎都是"刺杀结束后"），图生视频没有动作可插值；再叠加免费档 Seedance 1.0 是能力下限模型（无参考图→角色漂移）。**

流程层还有一个恶性循环在给这三层持续放血：规则堆叠 → LLM 后段失声 → 加 hard_fix 补丁 → 补丁本身制造新损坏 → 再加规则。

## 二、证据链（7 个关键发现）

**发现 1｜LLM 原始输出 vs 落盘脚本的巨大落差。** 原始 shot1 prompt："剑眉星目的杨旭，黑发束冠，素白轻袍……中远景，逆光剪影，暖金+绯红色调，缓慢推镜"（通顺、有电影感）。落盘版："剑（画中）眉星目……听香站立身旁，杨旭，杨旭，杨旭，杨旭，手持油纸伞（画中）……淡入淡出转场，转场时长0.5s。（AI生成）。危机一触即发，惊觉对"（破碎、截断）。

**发现 2｜已知 bug 未修，今天仍在产线跑。** v6.43 备忘录（08-23）明确记录"仰卧头部朝向追加到 ff_desc 末尾导致修饰对象错位——下一轮可改"，今天产物仍大面积出现："听香……张嘴欲呼，仰面朝上双目紧闭"（自相矛盾）、"无篷舴艋舟……仰面朝上双目紧闭"（修饰到船上）。其余：角色名复读 ×4、"（画中）"词中插入（剑眉/箫孔被误伤）与双标记、"暗红暗红"叠词（08-20 评估就记了 14 处）、prompt 尾部截断（"镜头推近至""惊觉对"）、shot 7/7.5/8.0 三个镜头 prompt 一字不差（拆镜照抄前镜）。

**发现 3｜新旧两套修复层混跑，今天实际跑的是旧路径。** 今天 step01.log 明确打出 `HARD_FIX_USE_OLD=1, 跳过所有 Constraint, 走旧 _hard_fix_* 路径`——即 v6.42→v6.49 这一个月建的 29 条新约束 + 468 个测试今天全部被绕过；该开关不在任何项目文件里（来自外部 shell 环境，来源需要查清）。同一份 log 还有测试残留跑进产线（`broken 异常: intentional failure`、`duplicate_append: a ↔ b` PoC 自检）、regen 对 shot2"轴线跳"重试 12+ 次无进展死循环、一次 regen JSON 解析失败保留原版、红果校验算出"总时长 5.0s < 60s"的荒谬数字。

**发现 4｜发往图片模型的 prompt 自相矛盾。** 今天 step02a.log 的真实提交样本：同一 prompt 内「【道具锚定】神秘人匕首在杨旭手中」vs「【武器归属】杨旭手中没有武器，没有刀，没有剑」；「总共2人，禁止出现任何其他人物、黑影、人影」vs 剧情核心伏笔恰是水下黑影（图里黑影因此消失）；角色描述块整体重复注入两遍；"。。"双句号；听香"鹿系脸"与"（头面部无任何动物特征…）"补丁并存；style prefix 繁简混排（統一五官/固定服裝）。

**发现 5｜首尾帧时序失效 → 视频必然没动作。** 实看图：钩子首帧（应为刺杀前：杨旭逍遥仰卧+水下黑影）渲染成匕首已插胸口；尾帧匕首还在+血更大——首尾两帧几乎相同，4 秒钩子视频只能是静态画面轻微形变，"破水刺杀"动作完全丢失。模型层原因（P22 已证：Seedream 对"刀尖微露水面竖直向下"类精确空间约束无解）+ prompt 层原因（首帧也被"胸口匕首依旧"类模板写成结束态）叠加。

**发现 6｜视频模型是能力下限的免费档。** Seedance 1.0 pro：无 reference_image（角色一致性核心机制被弃）、无声、仅首尾帧模式；Seedance 500 字符 prompt 硬上限，1500-1600 字被压到 200-500 且静默截断末尾约束。`.env.content` 自己的注释就写着"必须恢复 r2v（古风权谋角色一致性最关键）"。`clips/` 里只有 1 个 8月9日 的 clip——一个月调试精力几乎全部耗在 step01 和钩子首帧上，端到端从未跑通一集。

**发现 7｜流程恶性循环。** 26 个问题、约 50 个版本（v6.5→v6.49），每次症状→加规则/加 hard_fix/加防御模板；29k 字符 system prompt 后段 LLM 失声（v6.43 已确认）；单次跑批机械修复 283 处（等于系统默认"LLM 输出不可信"）；validation.py 6700+ 行；QC critical 被封顶为 warning（IMAGE_QC_WRITE_CRITICAL=0）→ 坏图静默流入视频生成。

## 三、优化方案（按优先级）

### P0 停血（1-2 天）：修确定性代码 bug，停止文本损坏
1. 修 4 个已证 hard_fix bug（与模型无关，修完立刻见效）：
   - 仰卧头部朝向追加位置错位 → 紧随"仰卧"插入且只作用于正确主语（v6.43 遗留项）
   - 角色名重复注入（杨旭×4）→ 定位注入循环加去重
   - "（画中）"标记改词边界匹配 + 已有标记去重（剑眉/箫孔误伤、双标记）
   - prompt 尾部截断 bug（"镜头推近至"丢尾）
2. 查清 HARD_FIX_USE_OLD=1 的注入来源，固定新旧路径二选一（建议：bug 修完前固定旧路径；之后单变量对比再决定是否切新框架）；移除产线里的 PoC/测试残留（a/b/broken）。
3. 修红果时长校验 bug；regen 同一镜头重试 >3 次无进展就放行带警告，禁止空转烧 token。
4. 打开 QC 拦截：IMAGE_QC_WRITE_CRITICAL=1 + QC_SEMANTICS_CRITICAL=1，让"匕首提前出现"这类帧当场拦住重生成（调试期额度换质量，值）。

### P1 图片保真（3-5 天）：让画面"画对"
1. **prompt 从"法条"回到"画面"**：目标 300-450 字 = 主体动作 + 环境 + 构图 + ≤5 个关键锚点（服装色/人数/威胁状态/道具方位）。删除：重复注入的描述块、与当前镜头时序无关的防御模板；防御模板按镜头 stage（pre/stab/post）动态选择，只带当前需要的锚。
2. **矛盾自检器**（step02a 提交前，代码层约 30 行）：同一 prompt 出现"A在B手中"+"B手中没有A"、"禁止黑影"+"黑影"这类对称矛盾即 fail-fast。这是防止 prompt 再次退化成法条堆的永久护栏。
3. **首尾帧时序协议**：ff=动作起始态、lf=结束态，加 schema 级校验（钩子 ff 禁止出现"洇痕扩大/匕首依旧"等 post 词——把现有 kf 时序检查思路推广到 ff/lf）。
4. characters_bank 听香"鹿系脸"改人类特征词（补丁与本体矛盾）；style prefix 繁体统一简体。

### P2 视频质量（图片达标后，约 1 周）：让画面"动对"
1. **恢复参考图机制（角色一致性命门）**，两条路各测 2-3 镜做 A/B 再定：
   - 免费额度烧完切回 bailian wan2.7-r2v（原方案、有声、一致性好）；
   - 或火山 Seedance 2.0 fast（支持 reference_image，付费）。
   - 若坚持用完免费 Seedance 1.0：接受角色漂移，把精力全部投 P0/P1（首尾帧质量是该模型下限内最大的可得收益）。
2. Seedance 500 字上限适配：精简路径（ff+motion+lf）此时携带的已是未损坏文本（P0/P1 的自然收益）。
3. **端到端跑通一集（step01→04）作为回归基线**：先有完整成片基线，再逐镜精调；避免继续陷在"永远在调钩子第一帧"。

### P3 流程治理（持续）
1. 冻结规则/模板增长：新问题先三选一归因（LLM 失声 / 模型能力边界 / 后处理 bug），只有"后处理 bug"才写补丁，前两类分别走"prompt 结构化减负"和"换能力/换镜头设计"。
2. 每轮改动只动一层并跑端到端验证（v6.49 一次 9 约束+4 prompt 改动的模式回归风险高）。
3. 每次跑批快照 script+最终 prompt+成图（output 不进 git，建立轻量备份），缺陷可回溯可对比。

## 四、预期效果
- P0 后：分镜文本立即恢复可读（"杨旭×4/剑（画中）眉/船闭眼"消失），regen 不再空转。
- P1 后：图片与剧情一致率显著提升（匕首不再提前出现、水下黑影回归、听香不再站水里/嘴角滴血）。
- P2 后：视频有真实动作（首尾帧拉开时序）+ 角色跨镜一致，最终成片达到可发布调试版。
- 核心观念转变：从"不信任 LLM 输出、用正则无限打补丁"，转向"最小后处理集合 + prompt 矛盾自检 + 按模型能力设计镜头"。
