# AI漫剧角色资产创建技能

> 基于 references/ai-character-asset-creation-guide.md 的方法论
> 用于角色肖像生成时的 prompt 工程参考

## 1. 基础图优先策略（核心方法论）

**错误做法**：直接生成三视图，导致角色细节、光影、质感不一致

**正确流程**：
1. 首先生成**单张基础全景图** → 锁定核心特征
2. 基础图确认后，上传作为参考
3. 基于基础图生成面部特写 + 三视图

## 2. 万能角色Prompt公式

```
[风格/画风] + [主体身份/年龄/性别] + [外貌细节] + [服装配饰] + [光影氛围] + [质量标签]
```

**示例**：
```
电影写实风格，24岁168cm中国女性，鹅蛋脸+深棕色眼睛+深色锁骨发，
穿着藏青工装夹克+黑色长裤，
主光从右前方45°照射，左侧补光，后上方轮廓光，色温5500K，
真实皮肤纹理，轻微胶片颗粒，8K高清，电影级质感
```

## 3. 强制一致性约束（必须添加）

生成三视图时，prompt 必须包含：
```
MUST match base image: face shape, hairstyle, clothing, body proportions, light source all consistent.
```

## 4. 光影标准（固定）

- 主光：45° 前方照射
- 补光：另一侧
- 轮廓光：后上方
- 色温：5500K
- 质感：真实皮肤纹理、轻微毛孔、布料褶皱、袖口磨损

## 5. 质量标签（固定）

- 轻微电影胶片颗粒
- 真实镜头微反差
- 轻微自然暗角
- 8K高清
- 电影级质感

## 6. 负面提示词（固定）

```
模糊、畸形、低分辨率、塑料皮肤、过度滤镜、动漫风格、动画、2D渲染、3D渲染
```

## 7. 资产命名规范

```
{剧本名称}-人物资产-{角色名称}
例如：废弃医院失踪案-人物资产-张青
```
